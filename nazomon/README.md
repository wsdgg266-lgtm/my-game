# 👾 なぞモン

小学2〜4年生向けの、2人で遊ぶなぞなぞアプリです。1台のスマホを交代で使い、なぞなぞに正解するとモンスターが進化します。勝ち負けはなく、2人とも最終形態まで育てたらクリアです。

ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで使えます。
スマホ(縦向き)向けです。ホーム画面に追加するとオフラインでも遊べます。

## あそびかた

1. 「あそぶ」→ 1P・2P がそれぞれ むずかしさを選ぶ(⭐ かんたん / ⭐⭐ ふつう / ⭐⭐⭐ むずかしい)
2. 2人にちがう種類のたまごが1つずつ届く(何が生まれるかはひみつ)
3. 交代でなぞなぞに答える。交代のたびに「つぎは ○○の ばん!」の画面が出る
4. 正解するとモンスターが育つ
   - 1回目で正解 → ゲージ 2マス(すぐ進化)
   - まちがえるとヒントが出て、もう1回。2回目で正解 → 1マス
   - 2回目もまちがい → 正解と「こたえのわけ」を見て交代(へったりはしない)
5. 最初の進化でたまごがかえり、名前をつける(6文字まで。「おまかせ」なら種族名で呼ぶ)
6. 先に最終形態になった人は「おうえんモード」。正解すると相手のモンスターが育つ
7. 2人とも最終形態になったらクリア。ずかんに登録される

- 1人4問正解で最終形態になるので、1回は10〜15分くらい
- 途中でアプリを閉じても「つづきから」で再開できる
- 効果音はホーム右上か ⏸ メニューでオン・オフ

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面と見た目 |
| `app.js` | ゲームの進み方・進化演出・ずかん・効果音・保存 |
| `quiz.js` | なぞなぞ 150問(かんたん・ふつう・むずかしい 各50問) |
| `monsters.js` | モンスター30体の絵と名前・説明 |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面に追加 |
| `icons/` | アイコン(`node scripts/make-nazomon-icons.mjs` で作り直せる) |

### なぞなぞを足すには

`quiz.js` の各むずかしさの配列の **最後に** `[もんだい, こたえ, [まちがい], ヒント, こたえのわけ]` を足します。
まちがいの選択肢は、かんたんは2つ、ふつう・むずかしいは3つです。
(途中に入れると、どの問題が出たかの記録がずれます)

## データの保存先

ずかん・途中のゲーム・出た問題・音の設定は端末のブラウザ(LocalStorage)に保存します。外部への送信はありません。
