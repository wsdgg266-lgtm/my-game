# 🎪 キタイベ！ - 北近畿のイベント＆チケット発売レーダー

北近畿(京都府北部・兵庫県北部)のイベントをジャンル別に探して、
**チケットの発売日を逃さない**ためのアプリです。
ビルド不要・サーバー不要で、公開URLをブラウザで開くだけで使えます。

公開URL: <https://wsdgg266-lgtm.github.io/my-game/events/>

> 公開はデフォルトブランチ(`claude/shopping-reminder-app-7xpyg5`)からのみ行われます。
> `github-pages` 環境のブランチ制限により、機能ブランチに push しても反映されません。
> 変更を公開するには、デフォルトブランチにマージしてください。

## このアプリの狙い

イベント情報を載せたサイトはたくさんあります。このアプリが違うのは、
**「情報を見せること」ではなく「買い逃さないこと」**に振り切っている点です。

人気イベントのチケットを取り逃す原因は、だいたい次の4つです。

| 取り逃す原因 | このアプリの対策 |
|---|---|
| 先行受付があったのを知らなかった | 先行を段階ごとに登録して、一般発売より前に知らせる |
| 発売開始の時間を忘れていた | 前日・1時間前・10分前のアラート＋カレンダー登録 |
| 発売の瞬間にもたつく | 10分前に**発売ダッシュ画面**が起動。販売ページのボタンを事前に並べておく |
| 抽選に申し込んだ後の期限切れ | 申込済み・当落発表日・入金期限をステータス管理 |

チケットの購入そのものはアプリ内では行いません(プレイガイドの規約・認証の都合で
現実的に不可能です)。**買う瞬間に最短距離で到達させる**ための道具です。

## 使い方

### 画面

| タブ | 内容 |
|---|---|
| 🏠 ホーム | 今日〜今週末のイベント。上部に「まもなく締切・発売」を固定表示 |
| 🔎 さがす | ジャンル × エリア × 日付 × チケット要否で絞り込み、フリーワード検索 |
| 🎟 発売 | **発売レーダー**。チケットの発売日・締切が近い順に並ぶ、このアプリの心臓部 |
| ⭐ マイ | 気になる／申込済み／当選・購入／落選 のステータス別。期限が近いものが最上部 |

ヘッダーの **📍** でエリア絞り込み、**＋** でイベントの手動追加、**⚙** で設定を開きます。
ジャンルのチップは複数選べます。

### 🚀 発売ダッシュ画面

イベントを開いて販売段階の **⏰ 発売アラート** に「10分前」を入れておくと、
発売の10分前にアプリを開いたときカウントダウン画面が自動で立ち上がります。

- 端末の時計は数十秒ずれていることがあるので、**サーバー時刻とのズレを補正**して
  0.1秒単位でカウントダウンします(精度はおよそ1秒)
- 販売ページのボタンを**事前に並べておく**ので、0秒になった瞬間に押せます
- 事前準備チェックリスト(会員登録・ログイン・支払い方法・枚数と席種)と
  メモ欄(会員番号の下4桁など。端末内にのみ保存)がついています

### ⏰ 通知は「カレンダー登録」が主軸

iPhone の Safari は**ホーム画面に追加したときしか**Web通知が使えません。
アプリを閉じている間も確実に知らせるため、発売日は
**カレンダー(.ics)か Google カレンダーに登録**しておくのがおすすめです。
イベント詳細の「📅 カレンダーに追加」から、受付開始・申込締切・当落発表・入金期限を
まとめて登録できます。

アプリ内の通知(前日/1時間前/10分前)は、アプリを開いている間の補助として動きます。

## イベントデータについて

同梱データは**すべて動作確認用のサンプル**で、実在のイベントではありません
(タイトルに【サンプル】と付いています)。実際に使うときは次のどちらかで入れ替えてください。

### 1. 手で登録する(確実)


ヘッダーの **＋** から、名前・日時・場所・ジャンル・発売日を登録します。
先行 → 一般のように**段階ごと**に登録でき、マラソン大会のエントリーや
ワークショップの予約も同じ形で扱えます。
登録が済んだら、設定の「サンプルデータを隠す」をONにしてください。

`events/data/events.json` を直接書き換えても構いません(形式は同ファイルを参照)。

### 2. 🏛 会場ウォッチで「発売前」に気づく（いち早く知るための本命）

ホールの**チケット発売情報ページ**は、公演がプレイガイドに並ぶより先に更新されることが
多いところです。ここを起点にすると、先行受付に間に合います。

例えば「吉本新喜劇出前ツアー2026【京都福知山市公演】」(10/3・福知山市厚生会館)は、
ファンクラブ抽選先行が6/20、一般発売が7/5でした。会場ページを見張っていれば
6月上旬の時点で気づけた、という種類のイベントです。

**発売タブ →「🏛 会場からいち早く見つける」**から、登録した会場の公演情報ページと
プレイガイドの会場ページをワンタップで開けます。初期登録は次の4会場です。

| 会場 | 市町 |
|---|---|
| 福知山市厚生会館 | 福知山市 |
| 舞鶴市総合文化会館 | 舞鶴市 |
| 京都府中丹文化会館 | 綾部市 |
| 豊岡市民会館 | 豊岡市 |

同じ画面から会場を自由に追加できます(会場名とページURLを入れるだけ)。

さらに `scripts/watch-venues.mjs` が**1日1回ページの更新を自動チェック**し、
変化があればホームに「🔔 会場ページに更新あり」として出します。
ページの中身を解析するのではなく「何か変わった」ことだけを確実に拾う方式なので、
サイトの作りが変わっても壊れません。判断はリンクを開いて人が行います。

### 3. 自動で取り込む(できたら儲けもの)

`.github/workflows/events-import.yml` が1日1回、自治体のオープンデータ(CKAN)から
イベント一覧を取り込んで `events/data/imported.json` を更新します。

ブラウザから直接よそのサイトを読むと CORS で弾かれるため、
**取得は GitHub Actions(サーバー側)で行い、結果をリポジトリに置く**方式にしています。
アプリは同一オリジンのJSONを読むだけなので、CORSの問題が起きません。

> **注意**: 取り込み先の実在確認は未実施です。この開発環境は外部サイトへの通信が
> 遮断されており、実際にデータが取れるかを試せていません。
> 初回は Actions タブから **Import events** を手動実行して、
> `events/data/import-report.json` にどのソースが使えたかを確認してください。
> 取れなくてもアプリは手入力データで問題なく動きます。
> 対象は `events/data/sources.json` で足し引きできます。

取り込みロジックだけはネットワークなしでテストできます。

```
node scripts/test-import.mjs
```

## 対象エリア

京都府北部・兵庫県北部の12市5町です。

| ブロック | 市町 |
|---|---|
| 丹後(京都) | 京丹後市・宮津市・与謝野町・伊根町 |
| 中丹(京都) | 舞鶴市・綾部市・福知山市 |
| 南丹(京都) | 南丹市・京丹波町・亀岡市 |
| 但馬(兵庫) | 豊岡市・養父市・朝来市・香美町・新温泉町 |
| 丹波(兵庫) | 丹波市・丹波篠山市 |

設定で「拡張エリア」をONにすると、福井県嶺南(敦賀・小浜など)と
滋賀県北部(長浜など)も対象になります。
自分の市町を登録すると、さがす画面に「近くだけ」の絞り込みが出ます。

## ジャンル

🎵 音楽・ライブ / 🎭 演劇・お笑い / 🍜 グルメ・マルシェ / 🧑‍🍳 体験・ワークショップ /
🏟 スポーツ / 🎨 アート・展示 / 👶 子ども向け / 🎆 祭り・花火 /
⛩ 伝統行事・神事 / 🌸 季節・自然

1つのイベントに複数のジャンルを付けられます
(例: 酒蔵開き = グルメ＋体験、こども工作教室 = 子ども向け＋体験)。

ジャンルのチップは横スクロールしますが、右端の **⌄** を押すと全ジャンルが
折り返して表示され、画面外のジャンルも一目で選べます。

## プレイガイドの検索リンク

イベント詳細から チケットぴあ / ローソンチケット / イープラス / 楽天チケット /
Google の検索結果をワンタップで開けます。

> 検索URLの形式は**未検証**です。サイト側の仕様変更でうまく開かないときは、
> 設定の「プレイガイド」でURLを直してください(`{q}` がイベント名に置き換わります)。

## iPhone / Android で使う(ホーム画面に追加)

PWA対応なので、ホーム画面に追加すると普通のアプリのように全画面で起動でき、
オフラインでも保存済みのイベントを見られます。

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」**

## データの保存先

「気になる」などのステータス、メモ、アラート設定、手動追加したイベントは、
すべてブラウザの LocalStorage に保存されます。端末の外には送信されません。
設定の「自分のデータを書き出す」でバックアップを取れます。
