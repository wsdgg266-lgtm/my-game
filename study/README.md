# 🎓 まなクエ!

小学3年生が、ゲームのように遊びながら学校の勉強(さんすう・こくご・りか・しゃかい)を
くりかえし練習できる学習アプリ。ビルド不要・サーバー不要で、`study/index.html` を
ブラウザで開くだけで使えます。

仕様の背景や決定事項は [../docs/SPEC-study.md](../docs/SPEC-study.md) を見てください。

## つかいかた(3ステップ)

1. **ぼうけん**タブで、やりたいステージ(たとえば「九九」)をタップ
2. 10問 こたえる(1〜2分)。おわると ★ と けいけんち がもらえる
3. まちがえた問題は **まちがえ直し** にたまるので、そこで もう一度 とく

名前・アイコン・むずかしさは **おうちのひと**タブで変えられます。

## ⚔️ 四神バトル

「ぼうけん」タブの **⚔️ 四神バトル** から、あいぼうの守護神を1人えらんでボスにいどみます。

- **正解すると あいぼうが こうげき / まちがえると ハートが 1つへる**。
  ボスのHPを 0 にしたら しょうり(ハートが 0 になると まけ)
- **コンボ**でダメージが上がり(3コンボ1.2倍・5コンボ1.5倍・10コンボ2倍)、
  ひっさつゲージが たまると **ひっさつ技(3倍ダメージ)**
- **守護神の とくせい**
  | 守護神 | とくせい |
  |---|---|
  | 🐉 青龍(せいりゅう) | こたえる時間が +10秒 |
  | 🐯 白虎(びゃっこ) | ハートが +2(5→7) |
  | 🔥 朱雀(すざく) | こうげき力が 1.3倍 |
  | 🐢 玄武(げんぶ) | たおれても 1回だけ 復活 |
- **きずなレベル**: 使うほど そのキャラの こうげき力が上がる(最大 +50%)
- **ボスは8体**。スライムこぞう → … → まなクエ王 まで、1体たおすと つぎが あらわれる
- 勝つと けいけんちが たくさん もらえ、ハートを へらさずに勝つと 💎むきず の バッジ

キャラの絵は `study/characters/` に入っています(差し替えたいときは同じファイル名で
webp 画像を置きかえてください)。

## 楽しく つづく しくみ

- **★1〜3**: ステージごとに 正答率で ★がつき、最高記録が残る(全21ステージ)
- **レベルとけいけんち**: 正解1問=10けいけんち。5コンボ以上は1.5倍、パーフェクトで+50
- **きょうのミッション**: 毎日3つ(「ステージを2つクリア」「20もん正解」など)。
  達成するとその場でボーナス
- **れんぞく日数**: 1日1ステージで カレンダーにスタンプ。連続日数と最高記録が残る
- **バッジ26種**: 「九九マスター」「かんじ100」「1しゅうかん」「四神づかい」など
- **60びょうチャレンジ**: 60秒で何問とけるかのタイムアタック(自己ベストが残る)

## ステージ(全21)

| 教科 | ステージ |
|---|---|
| 🔢 さんすう | たし算のひっ算 / ひき算のひっ算 / 九九 / かけ算のひっ算 / わり算 / あまりのあるわり算 / 大きい数 / 小数 / 分数 / 時こくと時間 / 長さと重さ / 円と三角形 |
| ✏️ こくご | かんじの よみ / かんじの かき(3年生の漢字200字を内蔵) |
| 🔬 りか | こん虫と生きもの / しょくぶつ / 光・音・じしゃく・電気 / 太陽とかげ・風とゴム |
| 🗾 しゃかい | 地図記号と方位 / 市のようす・はたらく人 / くらしを守る・むかしのくらし |

- さんすうの問題は**その場で自動生成**されるので、毎回ちがう問題が出ます
- 九九は**にがてな段が出やすく**なります(正答率の低い段を優先)
- 漢字の「かき」は、答えが1つに決まる ことばだけを出題します

## 👪 おうちのひと(見まもり)

- **7日間の 問題数・正答率・学習時間**
- **にがてな ところ**: 単元別の正答率を低い順に表示。九九は「7の だん」、
  漢字は「かんじの よみ『悪』」のように、つまずいている場所まで分かります
- **設定**: むずかしさ(やさしい/ふつう/むずかしい)、1ステージの問題数(5/10/20)、
  1問の制限時間(なし/20/30/45秒)、出題する教科のオンオフ、音、なまえ・アイコン
- **PIN(任意)**: 4桁を設定するとこのタブがロックされます(5分で自動再ロック)。
  未設定なら誰でも開けます
- **バックアップ**: JSONで書き出し・読みこみ、データのリセット

## データについて

- 学習の記録は**ブラウザの LocalStorage だけ**に保存され、端末の外には一切送信しません
- 通信もアカウント登録も不要です(オフラインでも動きます)
- 機種変更のときは「書き出す」でJSONを保存して、新しい端末で「読みこむ」

## iPhone / Android で使う(ホーム画面に追加)

PWA対応なので、公開URLをスマホで開いてホーム画面に追加すると、
アプリのようにアイコンから全画面で起動できます。

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」**

## 開発メモ

- 実装は `study/index.html` の1ファイル(HTML+CSS+JS)。ビルド不要
- アイコンを作り直すときは `node scripts/make-study-icons.mjs`
