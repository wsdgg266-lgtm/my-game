# 🃏 シールアルバム

**鬼滅の刃 ディフォルメシールウエハース 其ノ十五** のシールを、
スマホで **写真に撮って集めていく** コレクションアプリです。

撮るだけで自動的に四隅を見つけて**ななめの写真を正面の形に直し**、
台紙の白い部分を消して**シールの形どおりに切り抜き**ます。
ダブりの枚数、未所持のリスト、レアリティ別のコンプ率まで一目でわかります。

ビルド不要・サーバー不要。`seal/index.html` をブラウザで開くだけで動きます。

## 使い方

1. 右下の **📷** を押してシールを撮ります（台紙ごと撮ると四隅を見つけやすいです）
2. 四隅が自動で検出され、**「できあがり」**の見本が右上に出ます。
   ずれていたら白い丸をドラッグして直します
3. **「この形で登録する」** → 何番のシールかを選ぶとアルバムに入ります
4. マスをタップして **名前・レアリティ・枚数・メモ** を入力します
5. **2枚目からは自動です。** 一度登録したシールと同じものを撮ると、写真から見分けて
   **名前もレアリティもそのまま引き継ぎ**、ダブりとして枚数を足します
6. ダブりと未所持は「こうかん」タブにまとまります

> **自動でできること・できないこと**
>
> - ✅ **同じシールの見分け**: 一度登録したシールなら、次からは撮るだけで
>   その枠の名前・レアリティを引き継いで自動登録します（ウエハースはダブりが大半なので、
>   実際の入力の手間はほとんどこれで無くなります）
> - ✅ **キラ(箔)かどうか**: はじめて撮るシールでも、写真から
>   **ノーマル / レア** のどちらかを先に選んでおきます
> - ❌ **はじめて撮るシールのキャラ名**: 当てられません。端末内だけで完結させる作りのため、
>   キャラを見分けるAIを積んでいません。最初の1枚だけ名前を入力してください
> - ❌ **5thレア / 無限レア / シークレットの区別**: できません。キラと判定したものは
>   ひとまず「レア」にするので、タップで直してください
>
> 初期状態は No.1〜No.39 の空き枠です。名前の入力候補は作品の登場人物名で、
> 公式のラインナップ表ではありません。実物のパッケージや台紙を見ながら埋めてください。

## 画面

| タブ | 内容 |
|---|---|
| 📒 **アルバム** | 39枠のマス目。未所持/所持ずみ/ダブり/写真なし/レアリティで絞り込み。上部にコンプ率 |
| 🔁 **こうかん** | ダブり（出せる）と未所持（ほしい）の一覧＋そのままコピーできる交換募集の文面 |
| 📊 **しんちょく** | レアリティ別のコンプ率と、手に入れた日ごとの記録 |
| ⚙️ **データ** | アルバム名・枠の数の変更、バックアップの書き出し/読み込み、やりなおし |

## 機能

- **📷 撮って登録**: カメラ撮影のほか、撮影済みの写真を選んでも登録できます
- **🪄 四隅の自動検出**: 背景とシールの色の差から輪郭を割り出し、四隅を推定します。
  白い丸のドラッグで微調整でき、ドラッグ中は虫めがねで拡大表示されます
- **📐 台形補正**: ななめから撮った写真も、正面から見た形に直します（射影変換）
- **✂️ まわりを透明に**: 台紙の白い部分をたどって消し、シールの形だけを切り抜きます。
  背景が見つからないとき（シールぴったりに切り抜いたとき）や、
  消しすぎになるときは自動で見送り、四角いまま登録します
- **🔍 同じシールの自動判定**: 切り抜いた絵から「指紋」(4x4マスの色・色あいの分布・8x8マスの形・たてよこ比)を
  作って、登録ずみのシールと見くらべます。はっきり一致したときだけ自動登録し、
  迷うときは候補を並べて1タップで選べるようにします。取り違えたときは「ちがう」で取り消せます
- **✨ キラ(箔)の自動判定**: となり合う画素の色あいのばらつきと、こまかい白飛びの粒から、
  箔かどうかを推定してレアリティを先に選びます。露出オーバーの白飛びと取りちがえないよう、
  大きな白飛びは粒として数えません
- **🔢 ダブり管理**: 枚数を記録し、ダブり数をマスのバッジに表示します
- **🔁 交換リスト**: 「出せます / 探しています」の文面を自動で作成、コピー・共有できます
- **🏅 レアリティ**: ノーマル／レア／5thレア／無限レア／シークレットを色分けし、種類別のコンプ率を出します
- **💾 バックアップ**: 写真ごと、または文字データだけを JSON に書き出して読み込めます
- **📱 PWA**: ホーム画面に追加すると全画面で起動し、オフラインでも開けます

## プライバシー

写真・名前・枚数などは **すべて端末の中（IndexedDB）** に保存されます。
切り抜きや台形補正の計算もブラウザ内で完結し、**写真を外部に送信することは一切ありません**。

そのためブラウザのデータを消すとアルバムも消えます。機種変更の前や、
ときどき「データ」タブから書き出しておくと安心です。

## 注意

- **カメラは https のページでしか使えません**（`file://` やローカルの http では起動しません）。
  その場合はカメラ画面の「🖼 写真から選ぶ」から、撮影済みの写真を登録してください
- 枠の数は「データ」タブで増減できます（初期値は全39種。シークレット3種を含む数です）
