# 🛒 かいわすれナシ! - 買い忘れ防止アプリ

買い物の「買い忘れ」を防ぐためのシンプルな買い物リストアプリです。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで使えます。

## 使い方

`index.html` をブラウザ(スマホ推奨)で開くだけです。
データはブラウザの LocalStorage に保存されるので、閉じても消えません。

## iPhone / Android で使う(ホーム画面に追加)

このアプリは PWA(プログレッシブ Web アプリ)対応です。公開 URL をスマホで開いて
ホーム画面に追加すると、普通のアプリのようにアイコンから全画面で起動でき、
オフラインでも動作します。

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」または「アプリをインストール」**
  (インストールバナーが自動で表示される場合もあります)

公開 URL(GitHub Pages 有効化後):
`https://wsdgg266-lgtm.github.io/my-game/`

GitHub Pages はこのリポジトリの `.github/workflows/deploy-pages.yml` により
対象ブランチへの push で自動デプロイされます。初回のみ以下の設定が必要です。

1. (プライベートリポジトリの場合)GitHub Pages は無料プランでは公開リポジトリのみ
   対応のため、**Settings → General → Danger Zone → Change visibility** で
   リポジトリを Public にする(または GitHub Pro 等の有料プランを利用)
2. **Settings → Pages → Build and deployment → Source を「GitHub Actions」** に設定
3. **Actions タブ → Deploy to GitHub Pages → Run workflow** で再実行
   (以降は push のたびに自動でデプロイされます)

## 機能

- **お店の登録**: お店(スーパー、ドラッグストアなど)を複数登録でき、お店ごとに独立した買い物リストを管理。ヘッダーのタブで切り替え、未購入の点数がバッジで一目でわかる。選択中のタブをもう一度タップすると名前の変更・削除ができる
- **買い物リスト**: 品名とカテゴリ(食品・飲み物・日用品・その他)を指定して追加。カテゴリごとに整理して表示され、売り場を回りながらチェックしやすい
- **数量指定**: ＋/−ボタンで個数を変更
- **金額と合計**: 商品ごとに金額を入力でき(追加時または金額タグをタップして後から入力)、合計金額と未購入分の残り金額を自動計算して表示。一度入力した金額は「よく買うもの」からの再追加時にも引き継がれる
- **📰 近くのチラシ**: 住所を保存しておくと、選択中のお店の最新チラシをGoogle検索・トクバイ・Shufoo! からすぐに探せる。お店の設定(選択中タブを再タップ)からは「この店のチラシ」をワンタップ表示
- **✏️ 商品の編集**: 商品名をタップすると名前・カテゴリ・金額・内容量をまとめて修正できる
- **⚖️ お得計算**: 2商品の価格と内容量から100あたり単価を比較して、どちらが何%お得か判定。内容量を登録した商品はリストから選ぶだけ
- **💰 価格メモ**: 入力した金額を商品×お店×日付で自動記録。商品ごとに「安いお店」の順で表示され、使うほど最安の店がわかる
- **📷 バーコード読み取り**: 商品のJANコードをカメラで読むと商品名を自動入力。設定に楽天アプリID(無料)を登録すると楽天最安値も表示
- **🛒 ネット比較**: 商品編集・価格メモから Amazon・楽天市場・Yahoo!ショッピング・ヨドバシ の検索結果をワンタップで開ける
- **購入チェック**: タップで購入済みにでき、残り点数と進捗バーがヘッダーに常時表示される
- **🔍 買い忘れチェック**: レジに行く前にボタンひとつで「まだ買っていないもの」の一覧を表示。全部そろっていれば「買い物を終了する」でリストをリセット
- **⭐ よく買うもの**: 過去に追加した品物を**お店ごとに**追加回数順に記憶し、ワンタップで再追加。定番の買い物の入力の手間と「いつものアレの入れ忘れ」を防ぐ(チップの長押しで削除)
- **購入済みの一括削除**: 買い終わったものだけをまとめて片付け
