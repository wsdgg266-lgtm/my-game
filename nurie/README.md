# 🎨 いろいろぬりえ

4〜10歳向けの塗り絵アプリです。操作はなるべくシンプルにしてあり、ボタンは絵とひらがなだけで出しています。

- **バケツ**でタップした枠の中を一発でぬれる(4歳でもかんたん)
- **ペン・きらきらペン・スタンプ**で自由にかざれる
- **絵の具のおさら**で色を指でぐるぐる混ぜて、自分の色を作れる(きいろ+あお=みどり など)
- **撮った写真**を線画にして、その上からぬれる
- 下絵は 4 ジャンル × 8 枚 = **32 枚**(⭐ かんたん / ⭐⭐ むずかしい)

ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで使えます。
タブレット(iPad など)向けですが、スマホでも使えます。ホーム画面に追加するとオフラインでも動きます。
(写真を撮る機能を使うときは https の公開 URL で開いてください)

## 使い方

1. ホームで「えを えらぶ」「しゃしんで ぬりえ」「ぎゃらりー」のどれかを押す
2. 右の色を選んで、左の道具でぬる
3. 「✓ できた!」で紙ふぶき → ギャラリーに入る

### 道具

| 道具 | 動き |
|---|---|
| 🪣 ぬる | タップした枠の中を一発でぬる。ペンで描いたものの下にぬられるので、描いた絵は消えない |
| 🖍️ ぺん | 指でなぞってぬる。太さは 3 段階 |
| ✨ きらきら | にじ色にきらきら光るペン(色は自動) |
| ⭐ すたんぷ | ほし・ハート・はななど 10 種類。選んだ色で押す |
| 🧽 けしごむ | ぬった色を消す(下絵の線は消えない) |
| ↩️ もどす | 1 つ前にもどす(30 回まで) |

- 2 本指でひろげると拡大、2 本指で動かすと移動。「🔍 もとにもどす」で元の大きさにもどる
- 1 本指はいつでも「ぬる」なので、小さい子が迷わない

### 色まぜ(🎨 まぜる)

1. 下に並んだ色をタップすると、おさらに絵の具がぽとんと落ちる(3 色まで。同じ色を何回も入れると、その色が多めになる)
2. 指でおさらをぐるぐるこすると、だんだん混ざる。メーターがいっぱいになると「?」に混ざった色が出る
3. 「✓ できた!」で「じぶんの いろ」に入り、すぐに使える(8 色までおぼえる)

混ぜかたは絵の具に近い計算(RYB)にしてあるので、学校で習うとおり
「きいろ+あお=みどり」「あか+きいろ=オレンジ」「あか+あお=むらさき」「あか+しろ=ピンク」になります。

### 写真ぬりえ

- 「とる」でカメラ、「えらぶ」でアルバムの写真を使う
- 変換のしかたを 2 つから選べる(プレビューを見ながら切りかえられる)
  - **🎨 いらすと**:写真の色を数色の面にまとめて、ふちに線を引いたイラスト風にする。色がついた状態から始まり、バケツでタップすると面ごとに好きな色に塗りかえられる
  - **✏️ せんが**:線だけの白い塗り絵にする
- こまかさを「すくない / ふつう / おおい」から選べる(いらすとは色の数、せんがは線の量)
- 色の違い(黄色い花と緑の葉など)も見て線にするので、明るさが同じでもふちが出る
- 変換はすべて端末の中で行い、写真はどこにも送らない。ギャラリーには線画とぬった色だけを残す

### ギャラリー

- ぬっている途中も 15 秒ごと・おうちボタン・アプリを閉じたときに自動で保存
- 1 回もぬらずにもどった絵は保存しない
- 絵をタップすると続きからぬれる
- 消すときは 🗑️ を **3 秒長押し** → 確認(子どもがうっかり消さないように)

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面と見た目 |
| `app.js` | ぬる処理・色まぜ・写真の線画変換・保存 |
| `pictures.js` | 下絵 32 枚(SVG)。白でぬった図形は「線のない所」になる |
| `sw.js` / `manifest.webmanifest` | オフライン対応・ホーム画面に追加 |
| `icons/` | アイコン(`node scripts/make-nurie-icons.mjs` で作り直せる) |

### 下絵を足すには

`pictures.js` の各ジャンルの配列に `{ id, name, lv, d }` を足します。
`d` は 400×400 の SVG の中身で、ふつうの図形は白でぬられ、`${N}` を付けると線だけ、`${K}` を付けると黒くぬられます。
あとから描いた白い図形は、うしろの線をかくします。

## データの保存先

ぬった絵は端末のブラウザ(IndexedDB)、「じぶんの いろ」や音の設定は LocalStorage に保存します。
外部への送信はありません。
