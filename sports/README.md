# 🏟️ スポカレ！ - 試合日程・結果・視聴ガイド

プロ野球(NPB)と MLB の
「今日どの試合があって、どこで見れて、結果はどうだったか」が1画面でわかるアプリです。
MLBで戦う日本人選手の今季成績・評価も一覧できます。
ビルド不要・サーバー不要で、`sports/index.html` をブラウザで開くだけで使えます(PWA対応)。

公開URL: `https://wsdgg266-lgtm.github.io/my-game/sports/`
(スマホで開いて「ホーム画面に追加」すればアプリとして使えます)

## 機能

- **📅 日程・対戦カード**: 今日/明日/今後の試合を日付ごとに一覧。開始時刻は日本時間で表示
- **🏁 試合結果**: 終了した試合のスコアを日付ごとに一覧(勝ちチームを緑で強調)
- **📺 視聴先の表示**: リーグごとの視聴先(DAZNなど)を試合カードに表示。
  設定で編集でき、試合ごとに「地上波○○で19時〜」のようなメモも書ける。
  中継をすぐ探せる検索リンク付き
- **🇯🇵 MLB日本人選手**: 「日本人」タブに、MLBの日本出身選手を自動で全員リストアップ。
  打者は打率・本塁打・打点・OPS・盗塁、投手は防御率・勝敗・奪三振・WHIP の今季成績と、
  OPS/防御率から機械的に付けた★評価(絶好調〜不振)を表示。二刀流は両方の成績を1枚のカードに。
  「チームの試合を見る」でその選手のチームの日程・結果に即ジャンプ
- **リーグで絞り込み**: ヘッダーのチップで NPB / MLB を切り替え
- **⭐ チームのフォロー**: フォローしたチームの直近の試合をホームに表示。
  「このチームだけ表示」でアプリ全体を絞り込み
- **🧑‍🎽 注目の選手**: 選手名+所属チームを登録すると、その選手のチームの試合
  (日程・結果・視聴先)をワンタップで絞り込み表示
- **🩺 診断**: 設定タブでリーグごとのデータ取得状況(件数・取得元・エラー)を確認できる

## データについて

- 試合データは **ESPN**(MLB)と **TheSportsDB**(NPB、MLBの予備)、日本人選手の成績は
  **MLB StatsAPI** の公開APIからブラウザが直接取得します。APIキーや登録は不要です
- 日本人選手は「日本出身(birthCountry=Japan)の現役MLB選手」をAPIから自動抽出するため、
  新加入・移籍があっても手作業なしで一覧に反映されます
- 取得したデータは LocalStorage にキャッシュされ、オフラインでも最後に取得した内容を表示します
- TheSportsDB は有志更新のため、日本のリーグは反映が遅れたり抜けたりすることがあります。
  各試合カード・設定タブの公式サイト/スポーツナビへのリンクで正確な情報を確認できます
- 放送・配信チャンネルの自動データは存在しないため、リーグごとのプリセット(編集可)+
  試合ごとの手動メモ+検索リンクで補う設計です

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル構成(依存ライブラリなし)
- LocalStorage によるデータ永続化、Service Worker によるオフライン対応(PWA)
- モバイルファーストのレスポンシブデザイン
