# 🎮 横スクロールアクションゲーム 仕様案

> **実装状況**: `game/` に実装済み(アプリ名: ピコラン!)。
> 仕様どおり4ステージ+ボス・仮想ボタン・Web Audio合成のBGM/効果音・
> PWA対応で実装。ステージ地図は `index.html` 内の `LEVELS`(テキスト地図)で編集できる。
> 解像度は設計時の320×180から320×192(タイル16px×12行ちょうど)に変更した。

マリオのような横スクロールのジャンプアクションゲーム。
キャラクター・世界観はドット絵風の**オリジナルデザイン**とし、既存作品の
キャラクター・グラフィック・音楽は一切使わない(著作権的に安全な構成)。

既存アプリ(かいわすれナシ!・スポカレ!・ふくらぶ!)と同じ構成で作る:

- ビルド不要・単一HTML(`game/index.html`)・依存ライブラリなし
- PWA対応(ホーム画面に追加してフルスクリーンで遊べる・オフライン動作)
- 進行状況・ハイスコアは LocalStorage に保存

## 決定事項(ヒアリング結果)

| 項目 | 決定 |
|---|---|
| 対応デバイス | **スマホのみ**(タッチ操作・縦横どちらでも遊べるが横持ち推奨) |
| ゲーム要素 | 敵キャラ(踏んで倒す)・コイン&スコア・パワーアップ・ボス&ゴール演出 |
| ボリューム | ステージ3〜5個(→ **4ステージ構成**を提案、下記) |
| 見た目 | ドット絵風オリジナル(全グラフィックをコードで描画、画像ファイル不要) |
| サウンド | BGM+効果音(Web Audio で合成、音声ファイル不要、ON/OFF切替あり) |
| ミス仕様 | 残機3・中間地点あり・残機0でゲームオーバー |
| 想定ユーザー | **子どもも遊ぶ** → 優しめの難易度・わかりやすい操作 |

## ゲーム概要

- 主人公(オリジナルのドット絵キャラ)を操作して右へ進み、ゴールを目指す
- 敵は上から踏むと倒せる。横から触れるとダメージ
- コインを集めるとスコアが増える。コイン100枚で残機+1
- パワーアップアイテムでダメージを1回耐えられる状態になる
- 最終ステージの最後にボスがいて、倒すとクリア

## 操作方法(スマホ・タッチ)

画面下に半透明の仮想ボタンを常時表示:

- **左下**: ◀ ▶ ボタン(左右移動)
- **右下**: Ⓐ ジャンプボタン
  - 押す長さでジャンプの高さが変わる(短押し=小ジャンプ、長押し=大ジャンプ)
- マルチタッチ対応(移動しながらジャンプできる)
- 子ども向け配慮として、ボタンは大きめ・判定は実表示より広めにする

## ステージ構成(4ステージ案)

| # | テーマ | 特徴 | 新要素 |
|---|---|---|---|
| 1 | 🌿 草原 | 平坦で優しい入門ステージ | 基本操作・敵・コイン |
| 2 | 🕳️ 洞窟 | 暗めの配色、足場がやや複雑 | 落ちる床・上下に動く敵 |
| 3 | ☁️ 空 | 浮島ジャンプ、落下注意 | 動く足場・風の演出 |
| 4 | 🏰 城 | 最難関+最後にボス戦 | 溶岩(即ミス)・ボス |

- ステージはタイル(マス目)ベースで設計し、データはテキストの地図
  (文字=ブロック種別)で持つ → 後からステージ追加・調整がしやすい
- 各ステージの中間に**中間地点(旗)**があり、ミス後はそこから再開
- 1ステージの長さは1〜2分程度でクリアできる想定
- ステージ1をクリアするとステージ2が遊べる…という順次アンロック方式。
  一度クリアしたステージはステージ選択画面からいつでも遊び直せる

### 難易度方針(子ども対応)

- ステージ1は「落ちて死ぬ穴」をほぼ無くし、敵も少なく
- 崖から足が出ても一瞬はジャンプできる猶予(コヨーテタイム)や、
  着地直前のジャンプ入力の先行受付など、操作が優しく感じる仕組みを入れる
- ダメージを受けた直後は一定時間無敵(点滅)
- ボスは動きがゆっくりで、攻撃パターンが見て分かるものにする(3回踏むと勝ち)

## キャラクター(すべてオリジナル・ドット絵)

- **主人公**: 丸っこいドット絵キャラ(歩き・ジャンプ・やられのアニメーション)
- **敵1(てくてく)**: 地面を左右に歩く。踏むとぺちゃんこ
- **敵2(とげとげ)**: トゲ付きで踏めない。避けるかブロックで対処(ステージ2以降)
- **敵3(ふわふわ)**: 上下にふわふわ飛ぶ(ステージ2以降)
- **ボス**: 大型キャラ。ジャンプで踏みつけ×3回で撃破

## アイテム・ギミック

- **コイン**: 取るとスコア+10。100枚で残機+1
- **パワーアップ(ハートの実)**: 取ると「パワー状態」になり、ダメージを
  1回耐えられる(耐えると通常状態に戻る)。?ブロックから出る
- **?ブロック**: 下から叩くとコインやアイテムが出る
- **レンガブロック**: パワー状態のとき下から叩くと壊せる
- **ゴールの旗**: 触れるとクリア演出(旗が下りる+ファンファーレ+スコア集計)

## スコア・残機

- スコア: コイン+10 / 敵を踏む+100 / クリア時に残りタイムボーナス
- 残機3からスタート。ミス(敵・落下・溶岩)で残機−1、中間地点から再開
- 残機0でゲームオーバー → そのステージの最初からやり直し(スコアはリセット、
  アンロック済みステージは消えない)
- ステージごとのハイスコアを LocalStorage に保存して表示

## 画面構成

1. **タイトル画面**: ロゴ+「はじめる」+サウンドON/OFF
2. **ステージ選択**: 4ステージのカード(未クリアは🔒、クリア済みは⭐+ハイスコア)
3. **ゲーム画面**: 上部に スコア/コイン数/残機/タイム、下部に仮想ボタン
4. **クリア画面**: スコア集計 → 次のステージへ / ステージ選択に戻る
5. **ゲームオーバー画面**: リトライ / ステージ選択に戻る

## サウンド(Web Audio・音声ファイル不要)

- BGM: ステージテーマごとにレトロ風の短いループ曲を矩形波・三角波で合成
- 効果音: ジャンプ・コイン・踏みつけ・パワーアップ・ダメージ・クリア・ボス撃破
- 画面右上のボタンでいつでもON/OFF(設定はLocalStorageに保存、初期はOFFで
  タイトル画面で選ばせる ※スマホは初回タッチまで音が出せない制約のため)

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル(`game/index.html`)
- 描画: `<canvas>` に低解像度(例: 320×180)で描いて整数倍拡大 →
  くっきりしたドット絵表示(`image-rendering: pixelated`)
- ゲームループ: `requestAnimationFrame` + 固定タイムステップ(60fps相当)で
  端末の性能差があっても挙動が変わらないようにする
- 物理: 重力・可変ジャンプ・タイルベースの当たり判定
- カメラ: 主人公を追いかける横スクロール(画面中央よりやや左に置く)
- PWA: `manifest.webmanifest` + Service Worker(既存アプリと同じ方式)
- データ保存(LocalStorage): アンロック状況・ステージ別ハイスコア・サウンド設定
