# 🎓 まなクエ! 仕様案

> **実装状況**: `study/` に実装済み(アプリ名: **まなクエ!**)。
> ビルド不要・単一HTML・LocalStorage 保存で、既存アプリ(かいわすれナシ!・スポカレ!・
> ふくらぶ!・ピコラン!・ハナビカメラ・キタイベ!・ジャマケシ・バスナビ!・おてつだいバンク)と
> 同じ構成。

小学校**3年生**が、ゲームのように遊びながら学校の勉強(さんすう・こくご・りか・しゃかい)を
くりかえし練習できるアプリ。

- ビルド不要・単一HTML(`study/index.html`)・サーバー不要
- PWA対応(ホーム画面に追加してフルスクリーン起動・オフラインでも動く)
- データはブラウザの LocalStorage に保存(端末の外に一切送信しない)
- 通信は一切しないので、外部サービスの登録もアカウントも不要

## 決定事項(ヒアリング結果)

| 項目 | 決定 |
|---|---|
| 教科 | **さんすう + こくご(3年生の漢字200字) + りか・しゃかい** |
| キャラクター | **四神(青龍・白虎・朱雀・玄武)を あいぼうにして ボスと たたかう**バトルモードを用意する |
| 見せ方 | **ゲーム風ドリル**。1ステージ＝10問のチャレンジ形式。制限時間・コンボ・★評価・レベルアップ |
| やる気の仕組み | **アプリ内で完結**。けいけんち／レベル／★／バッジ／れんぞく日数／きょうのミッション |
| おうちの人 | **見まもり画面あり**。学習量・正答率・苦手な単元がわかり、難しさや出題範囲を設定できる |

### この決定が設計に与える影響

「ゲーム風ドリル」「アプリ内で完結」を選んだということは、このアプリは
**ごほうびで釣るのではなく、進み具合(プログレス)そのものを楽しむ** 作りにする、ということ。
そこで次の3点を設計の芯に据える。

1. **1回を短く終わらせる**。1ステージ＝10問(約1〜2分)。「もう1回」を押させる長さにして、
   1日に何度でも気軽に開けるようにする
2. **がんばりが必ず目に見えて残る**。★の数・レベル・バッジ・れんぞく日数・カレンダーのスタンプ。
   問題を解いた分だけ画面のどこかが必ず増える
3. **まちがいは減点ではなく“次のステージ”**。まちがえた問題は自動で
   「まちがえ直し」ステージにたまり、そこを解くとさらにけいけんちがもらえる

## 教科とステージ(全21ステージ)

### 🔢 さんすう(自動生成なので毎回ちがう問題が出る)

| ステージ | 内容 | 入力 |
|---|---|---|
| たし算のひっ算 | 2桁+2桁 〜 4桁+3桁 | テンキー |
| ひき算のひっ算 | くり下がりあり | テンキー |
| 九九 | 1〜9の段(苦手な段が出やすい) | テンキー |
| かけ算のひっ算 | 2桁×1桁 〜 2桁×2桁 | テンキー |
| わり算 | わりきれるわり算 | テンキー |
| あまりのあるわり算 | しょう と あまり を両方入力 | テンキー×2 |
| 大きい数 | 10倍・100倍・÷10、位取り | テンキー |
| 小数 | 0.1の位のたし算・ひき算 | テンキー(.あり) |
| 分数 | 同じ分母のたし算・ひき算、大小 | 4たく |
| 時こくと時間 | ◯分後・◯分前・かかった時間 | 4たく |
| 長さと重さ | mm/cm/m/km、g/kg/t の単位かんさん | テンキー |
| 円と三角形 | 半径・直径、二等辺三角形・正三角形 | 4たく |

むずかしさ(やさしい/ふつう/むずかしい)で数の大きさが変わる。

### ✏️ こくご(3年生で習う漢字200字を内蔵)

| ステージ | 内容 |
|---|---|
| かんじの よみ | 熟語を見せて読みを4たくで選ぶ(例: 「悪人」→ あくにん) |
| かんじの かき | 読みを見せて□に入る漢字を4たくで選ぶ(例: あくにん →「□人」) |

「かき」は **答えが1つに決まることばだけ**を出す(「は」だけでは 葉・歯・波 の
どれか決められないため、1字の言葉は「かき」では出題しない。「よみ」は200字すべて出る)。

### 🔬 りか / 🗾 しゃかい(3年生の教科書の範囲・4たく)

- りか: こん虫と生きもの / しょくぶつ / 光・音・じしゃく・電気 / 太陽とかげ・風とゴム
- しゃかい: 地図記号と方位 / 市のようす・はたらく人 / くらしを守る・むかしのくらし

## ⚔️ 四神バトル(キャラクターを使って たたかう)

学習をそのまま戦闘にするモード。**問題に正解すると あいぼうの守護神がボスを攻撃し、
まちがえると こちらのハートが減る**。ドリルの1問1問が攻撃になるので、
「もう1問」の動機がそのままボス撃破につながる。

### あいぼう(守護神4人)

| 守護神 | とくせい | ひっさつ技 |
|---|---|---|
| 🐉 **青龍**(せいりゅう・東) | かぜのはやさ: こたえる制限時間が **+10秒** | 蒼天龍撃! |
| 🐯 **白虎**(びゃっこ・西) | まもりのキバ: ハートが **+2**(5→7) | 白牙烈斬! |
| 🔥 **朱雀**(すざく・南) | ほのおのちから: こうげき力 **1.3倍** | 紅蓮鳳舞! |
| 🐢 **玄武**(げんぶ・北) | ときのめぐみ: 倒れても **1回だけ復活**(ハート2で復帰) | 玄氷永盾! |

キャラの絵はユーザー提供の画像を切り出して `study/characters/*.webp` に置く
(アイコン128px・立ち絵420px、合計約350KB。オフラインでも出るよう Service Worker がキャッシュする)。

### 戦闘のルール

```
正解 → 守護神が こうげき(ダメージ = 100 × コンボ倍率 × きずな倍率 × とくせい)
       ひっさつゲージ +20%
まちがえ / じかんぎれ → ハートが 1つ 減る
ゲージ100%のときに 正解 → ひっさつ技(ダメージ 3倍・専用演出)
ボスのHPが0 → しょうり / ハートが0 → まけ
```

- コンボ倍率: 3コンボ=1.2倍、5コンボ=1.5倍、10コンボ=2倍
- きずな倍率: そのキャラで正解するたび +1、10ポイントで きずなレベル+1(最大10)。
  1レベルごとに こうげき +5%(最大 +50%)
- ★評価: ハートが満タン=★★★ / 半分より多い=★★ / それ以外=★
- 勝利報酬: けいけんち **50 + ボスLv×30**(はじめての勝利は2倍)

|---|---|---|---|

## ゲームの仕組み

### 1ステージの流れ

```
ステージを選ぶ → 10問(設定で5/10/20問) → 1問ごとに ◯/✕ とせいかいを表示
   ・制限時間バーが減っていく(設定でオフにできる)
   ・れんぞく正解で「コンボ」がたまり、5コンボ以上はけいけんち1.5倍
                    ↓
結果画面: せいかい◯/10、★1〜3、もらったけいけんち、レベルアップ演出、
          新しいバッジ、まちがえた問題のふりかえり →「もういちど」/「マップにもどる」
```

### ★の評価

| 正答率 | ★ |
|---|---|
| 60%以上 | ★☆☆ |
| 80%以上 | ★★☆ |
| 100% | ★★★ |

★はステージごとに**過去の最高**が残る。

### けいけんちとレベル

- 正解 1問 = **10けいけんち**(5コンボ以上は15)
- ぜんもん正解 = **+50** のボーナス
- きょうのミッション達成 = **+30** ずつ
- レベルアップに必要なけいけんち: `100 + (レベル-1) × 50`

### れんぞく日数

1日に1ステージでもクリアするとカレンダーにスタンプがつき、れんぞく日数が1増える。
1日あくと1にもどる(最高記録は残る)。

### きょうのミッション

日付から自動で3つ選ばれる(例: 「ステージを2つクリア」「20もん正解する」
「パーフェクトを1回とる」「さんすうを1ステージやる」「まちがえ直しをやる」)。
達成するとその場でけいけんちがもらえ、3つ全部でさらにボーナス。

### まちがえ直し

まちがえた問題は最大60問まで自動でたまり、「まちがえ直し」ステージで出てくる。
正解すると、その問題はリストから消える(=苦手が減っていくのが目に見える)。

### 60びょうチャレンジ

60秒で何問正解できるかを競うタイムアタック(さんすうのミックス)。
自己ベストが残り、バッジの対象になる。

## おうちの人の見まもり画面

- **学習量**: きょう / この7日間 / ぜんぶ の 問題数・正答率・学習時間
- **7日間の棒グラフ**: 日ごとの問題数(正解/不正解の色分け)
- **にがてな単元**: 単元別の正答率を低い順に表示(3回以上やった単元のみ)。
  「7の段」「あまりのあるわり算」のように、どこでつまずいているかがすぐわかる
- **設定**: むずかしさ / 1回の問題数(5・10・20) / 制限時間(なし・20・30・45秒) /
  出題する教科のオンオフ / 音 / なまえ・アイコン
- **PIN(任意)**: 4桁を設定すると、おうちのひとタブがロックされる(未設定なら誰でも開ける)。
  5分さわらないと自動で再ロック
- **バックアップ**: JSONで書き出し・読みこみ、データのリセット

## データの持ち方(LocalStorage)

キー `manaque:v1` に1つのJSONで保存する。

```
{
  profile:  { name, avatar, xp },                  // レベルは xp から計算
  settings: { difficulty, count, timeLimit, sound, subjects:{math:true,...}, pin },
  stars:    { [unitId]: 0..3 },                    // ステージごとの最高★
  units:    { [unitId]: { t, c } },                // 出題数・正解数(苦手判定用)
  items:    { [itemKey]: { t, c } },               // 九九の段など細かい単位
  daily:    { 'YYYY-MM-DD': { q, c, sec, clears, perfect, review, missions:[] } },
  wrongs:   [ 問題のスナップショット, ... ],          // 最大60
  badges:   [ badgeId, ... ],
  streak:   { last, count, best },
  best:     { challenge },                         // 60びょうチャレンジの自己ベスト
  battle:   { partner, cleared:{bossId:★}, bond:{守護神id:P},
              winBy:{守護神id:回数}, wins, noDamage }   // 四神バトル
}
```

- 集計はすべて `daily` と `units` から毎回計算する(合計値を直接書き換えない)
- 問題そのものは保存しない(算数は毎回自動生成、漢字・理科社会はアプリ内蔵)。
  ただし**まちがえた問題だけ**はスナップショットを保存して復習に使う

## やらないこと(初期スコープ外)

- 通信・アカウント・クラウド同期(端末内で完結させる)
- 複数の子どもの切り替え(必要になったら おてつだいバンクと同じ方式で足せる)
- 手書き入力・音声読み上げ
- おてつだいバンクとのポイント連携(今回は「アプリ内で完結」を選択したため)
- 守護神どうしの対戦、装備やガチャなどの収集要素(バトルは学習の動機づけに絞る)
