# いろいろぬりえ 仕様書(案)

4〜10歳向けの塗り絵アプリ。色を自分で混ぜて作れることと、撮った写真を線画にして塗れることが特徴。

## 1. 基本

| 項目 | 内容 |
|---|---|
| 対象 | 4〜10歳 |
| 端末 | タブレット中心(iPad等)。スマホでも動く。横向き・縦向き両対応 |
| 置き場所 | `my-game/nurie/`(単独PWA。ホーム画面に追加でき、オフラインで動く) |
| 構成 | ビルド不要の静的ファイル(`index.html` + `sw.js` + `manifest.webmanifest` + 下絵SVG) |
| 文字 | 絵アイコン+小さくひらがな。漢字は使わない |
| データ | すべて端末内(IndexedDB)。外部送信なし |

## 2. 画面

1. **ホーム** — 大きなボタン3つ
   - 🖼 「えをえらぶ」→ 下絵一覧
   - 📷 「しゃしんでぬりえ」→ 写真取り込み
   - 📁 「ギャラリー」→ 保存した絵
2. **下絵一覧** — ジャンルのタブ(絵アイコン)+サムネイル。各絵に ⭐(かんたん)/⭐⭐(むずかしい)表示
3. **塗り画面** — 中央にキャンバス、左右(縦向き時は下)に道具とパレット
4. **ギャラリー** — 保存した絵のサムネイル。タップで続きから塗れる

## 3. 塗り画面の道具

画面に出す道具は最大6つに絞る。

| 道具 | 動き |
|---|---|
| 🪣 バケツ | タップした枠の中を一発で塗る。線のすき間から漏れにくいよう、少し太らせた線で判定 |
| 🖍 ペン | 指でなぞって塗る。太さ3段階(ほそい/ふつう/ふとい) |
| ✨ キラキラペン | にじ色・ラメのペン。色はパレットに関係なく自動 |
| ⭐ スタンプ | ほし・ハート・はな・おんぷなど約10種。選んだ色で押す |
| 🧽 けしゴム | 塗った色だけ消える(下絵の線は消えない) |
| ↩ もどす | 1つ前に戻す(最大30回) |

- 線画は常に一番上のレイヤーに置き、塗りで線が消えないようにする
- 2本指で拡大・移動(細かい絵用)。1本指は常に「塗る」

## 4. 色と色まぜ

### パレット
- 基本の色12色(あか・きいろ・あお・しろ・くろ・ちゃいろ など)を大きな丸ボタンで表示
- 下に「マイいろ」欄:自分で作った色を最大8個まで保存

### 絵の具皿(色まぜ)
1. 🎨 ボタンで絵の具皿が開く
2. パレットの色をタップすると、皿に絵の具がぽとんと落ちる(2〜3色まで)
3. 指で皿をぐるぐるこすると、だんだん色が混ざっていく(混ざる様子がマーブル模様で見える)
4. 「できた!」で混ざった色が「マイいろ」に入り、すぐ使える
5. 🗑 で皿を洗う(リセット)

- 混色は**絵の具っぽい混ざり方**にする(あお+きいろ=みどり になる。光の足し算だと灰色っぽくなるため、減法混色に近い計算を使う)
- しろを混ぜると明るく、くろを混ぜると暗くなる

## 5. 写真ぬりえ

1. 「とる」(カメラ起動)または「えらぶ」(アルバムから)
2. 写真を自動で**線画(輪郭線)**に変換
3. 線の量を3段階で選べる:すくない / ふつう / おおい(プレビューを見ながら)
4. 「これでぬる」で塗り画面へ

- 変換は端末内で処理(写真はどこにも送らない)
- 処理:縮小 → ぼかし → 輪郭抽出 → 細かいノイズ除去 → 線を太らせる(バケツが使いやすいように)

## 6. 下絵(内蔵)

- 全32枚。Claude が SVG で描く(後から差し替え可能)
- 各ジャンル8枚、うち半分は太線の「かんたん」、半分は細かい「むずかしい」

| ジャンル | 例 |
|---|---|
| 🐶 どうぶつ・いきもの | いぬ、ねこ、うさぎ、ぞう、きょうりゅう、さかな、ちょうちょ、かめ |
| 🚗 のりもの | くるま、でんしゃ、ひこうき、ふね、しょうぼうしゃ、バス、ロケット、じてんしゃ |
| 🍰 たべもの・おはな | ケーキ、アイス、りんご、いちご、ドーナツ、チューリップ、ひまわり、バラ |
| 🎄 きせつ・ぎょうじ | クリスマス、ハロウィン、ひなまつり、こどものひ、おしょうがつ、はなび、ゆきだるま、たんじょうび |

## 7. 保存・ギャラリー

- 塗り画面を出るとき・一定時間ごとに自動保存(「ほぞん」ボタン不要)
- ギャラリーから選ぶと続きから塗れる
- 削除は**保護者ロック**付き:ゴミ箱を長押し(3秒)→ 確認、で消える。子どもの誤操作を防ぐ
- 写真の元画像はギャラリーに残さない(線画だけ保存)

## 8. 音・演出(控えめ)

- バケツで塗ったとき「ぽん」、スタンプで「ぴょん」などの短い効果音
- 「できた!」ボタンで紙ふぶき+ギャラリーへ
- 音は右上のスピーカーボタンでON/OFF(設定は保存)

## 9. 対象外(今回はやらない)

- 端末の写真アプリへの保存・共有
- 印刷
- オンライン機能・アカウント
- BGM・キャラクター

## 10. 作る順番(案)

2. 絵の具皿(色まぜ)
3. 写真ぬりえ(線画変換)
4. ギャラリー・自動保存・削除ロック
5. スタンプ・キラキラペン・音
6. 下絵を32枚にそろえる、PWA化
