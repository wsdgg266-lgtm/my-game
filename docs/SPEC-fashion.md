「最近の流行り」「近くのお店」「お得情報」が1つのアプリでわかる、
ファッションのポータルアプリ。

既存の「かいわすれナシ!」「スポカレ!」と同じ構成
(ビルド不要・単一HTML・PWA・LocalStorage)で作る。

## 対象ユーザー(方針: 誰でも使える汎用)

初回起動時にかんたんな設定を行い、表示内容を絞り込む:

- **カテゴリ**: レディース / メンズ / キッズ(複数選択可)
- **年代**: 10代〜50代以上(楽天ランキングAPIの絞り込みに利用)
- **好きなブランド**: よく買うブランドを登録(後からいつでも追加・削除可)

設定は「設定」画面からいつでも変更できる。家族で使う場合は
カテゴリを複数オンにすれば切り替えタブが出る。

## 機能① トレンド(今っぽいアイテム+ECの売れ筋)

方針: **自動取得を最優先**。取れるデータ源はアプリ内に自動表示し、
取れないサイトはワンタップで開けるリンク集で補完する。

### 自動表示(要検証・手順0)

- **楽天市場ランキングAPI** (`IchibaItem/Ranking`) から
  ファッション系ジャンルの売れ筋ランキングを取得してアプリ内にカード表示
  - ジャンル例: レディースファッション / メンズファッション / 靴 / バッグ
  - 性別・年代パラメータで初回設定に合わせた絞り込み(対応状況は手順0で確認)
  - 商品カードから楽天の商品ページへワンタップ
- 取得結果は LocalStorage にキャッシュし、オフライン時・API障害時は
  「最後に取得したデータ+取得日時」を表示(スポカレ!と同じ方式)
- 予備候補: **Yahoo!ショッピングAPI**(こちらも無料のアプリIDで取得可能。
  楽天だけで十分なら初期は見送り)

### リンク集で補完(公開APIが無いもの)

- ZOZOTOWNランキング / WEARコーデランキング / Instagramタグ検索
- ユニクロ・GU等の新作/限定価格ページ
- リンク先は登録ブランド・カテゴリ設定に合わせて出し分ける

## 機能② お店(3つの使い方すべて対応)

1. **よく行くお店の登録・管理**
   - 店名・場所(住所やビル名)・公式サイトURL・セール情報URL・メモを登録
   - お店カードから Googleマップ(経路)・公式サイト・セールページへワンタップ
2. **現在地周辺のお店を探す**
   - 位置情報(または保存した住所)から Googleマップ検索を開く
   - 「古着屋」「ファッションビル」「アウトレット」「靴屋」などの
     カテゴリボタンをワンタップで周辺検索(かいわすれナシ!のチラシ検索と同じ方式)
3. **特定ブランドの店舗検索**
   - 登録ブランドごとに「店舗検索ページ」(例: ユニクロ店舗検索)への
     リンクを持ち、ワンタップで最寄り店舗を調べられる
   - 主要ブランドの店舗検索URLはプリセットで内蔵し、編集可能にする

## 機能③ お得情報(セールカレンダー+ブランドのセール・クーポン)

1. **年間セールカレンダー**
   - 定番セールをプリセットで内蔵:
     夏バーゲン(7月)/ 冬バーゲン(1月)/ 楽天スーパーセール(3・6・9・12月)/
     お買い物マラソン / ブラックフライデー(11月)/ ゾゾセール / アウトレットセール など
   - 開催時期が毎年変わるものは編集でき、自分のお店・ブランドのセールも追加できる
2. **起動時のお知らせバナー**(サーバー無しのためプッシュ通知は行わない)
   - アプリを開いたときに「開催中」「まもなく開始(7日前から)」のセールを
     ホーム上部にバナー表示
3. **ブランドのセール・クーポン**
   - 登録ブランドごとに公式セールページ・クーポンページ・アプリ会員証等への
     リンクを紐づけ、ワンタップでアクセス

## 画面構成

1. **ホーム**: 開催中・直近セールのバナー+今日のトレンドピックアップ
   (ランキング上位数件)+よく行くお店へのショートカット
2. **トレンド**: 楽天ランキングのカード一覧(カテゴリタブ切替)+補完リンク集
3. **お店**: 登録店リスト / 周辺検索ボタン / ブランド店舗検索
4. **お得**: セールカレンダー(月別一覧)+ブランドのセール・クーポンリンク
5. **設定**: カテゴリ・年代・ブランド管理、楽天アプリID、住所、
   データ再取得、キャッシュクリア

## データ設計(LocalStorage)

- `profile`: カテゴリ(レディース/メンズ/キッズ)・年代
- `brands`: 登録ブランド(名前・公式URL・店舗検索URL・セールURL・クーポンURL)
- `shops`: 登録したお店(店名・場所・URL類・メモ)
- `saleEvents`: セールカレンダー(プリセット+ユーザー編集・追加分)
- `rakutenAppId`: 楽天アプリID(かいわすれナシ!と同じIDを使い回せる)
- `cache`: ランキング取得結果と取得日時(ジャンルごと)
- `address`: 周辺検索用の保存住所(任意)

## 作成する順番(おすすめ)

0. **技術検証(最初にやる・最重要)**: 楽天ランキングAPIがブラウザから
   取得できるか、ファッション系ジャンルID・性別/年代絞り込みの動作を確認する。
   取れない場合はトレンドを「リンク集中心」に方針転換する
1. **骨組み**: 画面レイアウト+タブ+初回設定(カテゴリ・年代)
2. **トレンド**: ランキング取得 → カード表示 → キャッシュ+補完リンク集
3. **お店**: 登録・管理 → 周辺検索 → ブランド店舗検索プリセット
4. **お得**: セールカレンダー(プリセット+編集)→ 起動時バナー
5. **ブランド連携の仕上げ**: ブランド登録とセール・クーポン・店舗検索の紐づけ
6. **仕上げ**: PWA化(オフライン対応・ホーム画面追加)、公開方法の決定

順番の理由: トレンドの自動取得が実現性の鍵なので最初に検証する。
お店・お得はリンクと手元データ中心で確実に作れるため、後からでも安全。
