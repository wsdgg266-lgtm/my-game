# なぞモン 仕様書

小学2〜4年生向けのなぞなぞアプリ。2人が1台のスマホを交代で使い、なぞなぞに正解するたびに自分のモンスターが進化していく。勝ち負けはなく、2人とも最終形態まで育てたらクリア。

> 「仮」と書いたところは、あとで変えやすい決めごとです。

## 1. 基本

| 項目 | 内容 |
|---|---|
| 対象 | 小学2〜4年生、2人で遊ぶ(きょうだい・友だち) |
| 端末 | スマホ中心(縦向き)。タブレットでも動く |
| 置き場所 | `my-game/nazomon/`(単独PWA。ホーム画面に追加でき、オフラインで動く) |
| 構成 | ビルド不要の静的ファイル(`index.html` + `app.js` + `quiz.js` + `monsters.js` + `sw.js` + `manifest.webmanifest`) |
| 文字 | ほぼひらがな・カタカナ。漢字は使わない。大きめの文字 |
| データ | すべて端末内(LocalStorage)。外部送信なし |
| 音 | 効果音あり(Web Audioで合成、音声ファイルなし)。ホーム右上で ON/OFF |

## 2. 遊びの流れ

1. **ホーム** — 「あそぶ」「ずかん」「つづきから」(途中のゲームがある時だけ)
2. **むずかしさ選び** — 1P(あか)・2P(あお)がそれぞれ選ぶ
   - ⭐ かんたん(2年生くらい)/ ⭐⭐ ふつう(3年生くらい)/ ⭐⭐⭐ むずかしい(4年生くらい)
3. **たまごをもらう** — 2人にランダムのたまごが1つずつ。2人は別の種類になる(仮)
4. **交代でなぞなぞ** — 1P → 2P → 1P … の順に1問ずつ
5. **たまごがかえる** — 最初の進化でたまごがかえり、その子に名前をつける(6文字まで。「おまかせ」や空欄ならしゅぞく名で呼び、進化すると呼び名も変わる)
6. **進化** — 正解するたびに成長、5段階目(最終形態)まで
7. **クリア** — 2人とも最終形態になったらクリア画面。ずかんに登録

## 3. 1問の流れ

1. 交代画面「つぎは ○○(モンスター名)の ばん!」→ タップで問題へ(相手の問題をのぞき見しにくくする)
2. 問題と選択肢を表示
   - かんたん:3択 / ふつう・むずかしい:4択(仮)
   - 制限時間なし
3. **1回目で正解** → ピンポン音+「せいかい!」→ 成長ゲージ **2マス**
4. **1回目で不正解** → 選んだ答えをグレーにして **ヒント** を表示 → もう1回
   - 2回目で正解 → 成長ゲージ **1マス**
   - 2回目も不正解 → 正解と「こたえのわけ」を表示、ゲージは増えない(減りもしない)
5. 次の人の番へ

## 4. 成長と進化

| 段階 | 見た目 | 次の進化まで |
|---|---|---|
| 1 | たまご | 2マス |
| 2 | ベビー | 2マス |
| 3 | こども | 2マス |
| 4 | おとな | 2マス |
| 5 | さいしゅうけいたい | — |

- ゲージが2マスたまると進化。最短で4問正解すると最終形態(1人あたり約5〜10問、ゲーム全体で10〜15分くらい)
- 進化演出:モンスターが光ってぶるぶる→新しい姿+「○○は △△に しんかした!」+ファンファーレ
- 退化はしない

### 先に最終形態になったら(おうえんパワー)
- 交代はそのまま続く
- 最終形態になった人が正解すると、その分のゲージが **相手のモンスター** に入る(「おうえんパワー!」演出)
- 2人とも最終形態になったらクリア

## 6. なぞなぞ

- 全150問(かんたん・ふつう・むずかしい 各50問)
- 1問のデータ:問題文 / 選択肢 / 正解 / ヒント / こたえのわけ / むずかしさ
- 例(かんたん):「パンは パンでも たべられない パンは なーんだ?」→ フライパン
  - ヒント:「りょうりに つかう どうぐだよ」
- ジャンルの例:ことばあそび・だじゃれ / いきもの / たべもの / どうぐ / からだ / ちょっとかんがえる問題
- 1回のゲーム中に同じ問題は出ない。過去に出た問題はなるべく後回し(端末に記録)
- 子どもが読んでわかる表現にする。こわい・いじわるな内容は入れない

## 7. 画面(スマホ縦向き)

```
┌──────────────────┐
│ [1P モンスター] [2P モンスター] │ ← 小さめ。ゲージ表示。今の番の人が光る
│   ■■□           ■□□          │
├──────────────────┤
│                                    │
│   パンは パンでも                  │ ← 問題(大きい文字)
│   たべられない パンは?            │
│   💡ヒント(まちがえた時だけ)      │
├──────────────────┤
│ [ フライパン ] [ メロンパン ]      │ ← 大きな選択肢ボタン
│ [ しょくパン ] [ あんパン  ]       │
└──────────────────┘
```

- ボタンは指で押しやすい大きさ(高さ60px以上)
- 1P はあか、2P はあおで色分け
- 右上に ⏸(やめる/音のON・OFF)

## 8. ずかん

- 150マス(30系統×5段階)。出会ったモンスターは絵と名前、まだのものはシルエット「???」
- タップでくわしく:しゅぞく名・ひとこと説明(例「ねるとき しっぽの ひが ちいさくなる」)
- 「そだてたモンスター」:これまで育てた子の、つけた名前と最終形態を新しい順に記録(最大30件)
- ずかんの記録は2人共通(端末に1つ)

## 9. 保存

- 途中のゲームは自動保存。アプリを閉じても「つづきから」で再開できる
- ずかん・出題済みの問題・音の設定も保存
- ずかんのリセットはなし(仮)

## 10. 作らないもの

- 通信対戦・ランキング・ログイン
- 勝ち負けの表示、制限時間
- プレイヤー名の入力(1P/2P とモンスター名で区別)
- 読み上げ機能
