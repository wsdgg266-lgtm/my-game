# 🪙 おてつだいバンク 仕様案

> **実装状況**: `points/` に実装済み(アプリ名: **おてつだいバンク**)。
> ビルド不要・単一HTML・LocalStorage 保存で、既存アプリ(かいわすれナシ!・スポカレ!・
> ふくらぶ!・ピコラン!・ハナビカメラ・キタイベ!・ジャマケシ・バスナビ!)と同じ構成。

小学生の子どもが **おてつだい** と **べんきょう** をやるとポイントがたまり、
たまったポイントを **本物のお小遣いに交換できる** アプリ。

- ビルド不要・単一HTML(`points/index.html`)・サーバー不要
- PWA対応(ホーム画面に追加してフルスクリーン起動・オフラインでも動く)
- データはブラウザの LocalStorage に保存(端末の外に一切送信しない)

## 決定事項(ヒアリング結果)

| 項目 | 決定 |
|---|---|
| 換金方式 | **1P = 1円で自由に換金**。レートは親が設定変更できる(1P=1円/5円/10円など) |
| 承認フロー | **親の承認が必要**。子が「できた!」→ 承認まち → 親がまとめて承認してポイント確定 |
| 端末・人数 | **1台を家族で共有・子ども複数**。上部で子を切り替え、親モードは4桁PINでロック |
| 勉強の記録 | **チェック式のみ**(宿題やった・音読した等)。勉強タイマー/テスト点数ボーナス/れんぞく記録は初期スコープ外 |

### この決定が設計に与える影響

「1P=1円の自由換金」＋「親の承認必須」を選んだということは、このアプリは
**ごほうびゲームではなく、家庭内の小さな“お金の仕組み”** として使われる、ということ。
そこで次の3点を設計の芯に据える。

1. **ポイント残高＝お金**として扱う。残高はいつでも「◯P = ◯円」と併記し、
   子ども自身が「あといくら貯めれば◯◯が買えるか」を自分で計算できるようにする
   (算数の練習も兼ねる)
2. **お金がからむ操作は必ず親の手を通す**。ポイントの加算(承認)、減点、換金、
   レート変更、データ消去はすべて親モード(PINロック)の中だけで行える
3. **記録が必ず残る**。承認・却下・換金は日時つきで履歴に残り、
   「言った/言わない」でモメないようにする(実際に現金を渡してから
   「わたした」を押す運用にして、二重払いを防ぐ)

## 画面構成(下タブ4つ)

| タブ | 対象 | 内容 |
|---|---|---|
| 🏠 **きょう** | 子 | ちょきんの めあて(進み具合)＋今日やれるタスク一覧。タップ→「できた!」で承認まちへ。残高と円換算を大きく表示 |
| 📅 **きろく** | 子 | 今週/今月にためたポイント、日ごとのスタンプ、これまでの履歴(承認まち・承認済み・却下) |
| 💰 **こうかん** | 子 | 残高を円に交換する申請。プリセット(100円/500円/1000円/ぜんぶ)＋自由入力。申請中・受取済みの履歴。受け取った分は「なにに つかった?」を記録できる |
| 📊 **ふりかえり** | 子 | おこづかい帳。今月のためた／つかった／のこり、6か月の棒グラフ、使いみちの内訳、ためた内訳、めあてまでの見通し |
| 👪 **おうちのひと** | 親 | PIN入力後: 承認まちの一括承認、換金申請の処理、タスク編集、子ども管理、レート/PIN設定、手動でポイント増減、バックアップ |

### 子ども切り替え

ヘッダーに子どもチップ(絵文字＋名前＋残高)を並べ、タップで切り替える。
子どもは自分の残高・タスク・履歴だけを見る(他の子のポイントは編集できない)。

## ポイントが動く流れ

```
[子] タスクを「できた!」でタップ
        ↓  status: pending(承認まち・残高には入らない)
[親] おうちのひとタブ → 承認まち → 「ぜんぶ承認」または個別に ✓ / ✕
        ↓  status: approved(残高に加算) / rejected(0のまま履歴に残る)
[子] こうかんタブ → 「500円にかえる」で申請
        ↓  status: pending(その分の残高は“申請中”として確保され、二重に使えない)
[親] 現金を渡す → 「わたした」をタップ
        ↓  status: paid(残高から差し引き・履歴に日付つきで残る)
```

### 残高の計算(ズレを防ぐため必ず履歴から導出する)

```
使えるポイント = 承認済みタスクの合計
               + 親の手動増減の合計
               − 換金申請中(pending)のポイント
               − 換金済み(paid)のポイント
```

残高という数値を直接書き換えることはしない。すべて履歴(logs / cashouts)から
毎回計算するので、途中でアプリを閉じても不整合が起きない。

### タスクにないがんばり

タスク一覧に無いことをした時のために、親モードから **ポイントを直接あげる/ひく** 操作を用意する
(理由を書くと履歴に残る)。自動減点は入れない方針なので、引くのもここからの手動のみ。

## ちょきんの めあて(貯金の目標)

ポイントを「ためる理由」を子ども自身が持てるように、ほしいものを1つ登録できる。

| 項目 | 内容 |
|---|---|
| 登録するもの | 絵文字・ほしいもの・ねだん(円) |
| だれが決める | **子ども自身**(お金は動かないのでPINなしで設定・変更できる) |
| 表示 | 「きょう」タブのいちばん上に進みバー。**あと◯円（◯P）**と「いまのお金 / めあて」を併記 |
| たまったとき | バーが100%になり「🎉 たまったよ! こうかんできる」に変わる。下タブの「こうかん」にも印がつく |
| こうかんするとき | 換金の確認画面に「めあての◯◯までは あと◯円になるよ」と出して、使うか貯めるかを自分で選ばせる |

めあては子どもごとに1つ(兄弟はそれぞれ別のめあてを持てる)。
めあてを消してもためたポイントは減らない。

## 学習になる要素: おこづかい帳(ふりかえり)

ドリルを足すのではなく、**自分の本物のお金の記録で学ぶ**方向にした。
架空の問題より、自分が稼いだ数字のほうが子どもは真剣に見るし、
このアプリはその数字をすでに全部持っているため。

| 見せるもの | 学べること |
|---|---|
| **ためた − つかった ＝ ふえた分** を式のかたちで表示 | おこづかい帳の基本(収入・支出・残高の関係)。式として毎月目にする |
| 6か月の棒グラフ(ためた=オレンジ／つかった=青) | 自分のお金の増減を時系列で読む。グラフの読み取りそのものの練習 |
| **なにに つかった?** の内訳(円と%) | 支出を分類して割合で見る。「おかしに8割」を自分で発見する |
| **なにで ためた?** の内訳(おてつだい/べんきょう＋よくやったことベスト3) | 収入の内訳。どの行動がいくらになっているかの対応づけ |
| **めあてまで あと◯日**(直近30日の1日あたり平均から見積もる) | 平均・ペース・割り算。「1日4円ペースなら3,000円は◯日」という見通しの計算 |

### 使いみちの記録

換金は「◯円もらった」で終わらせず、**使いみち**を子ども自身が記録する。

- 種類: 🍭おかし・ジュース / 🧸おもちゃ / 🎮ゲーム / 📚本・まんが / ✏️ぶんぼうぐ /
  🎁プレゼント / 🐖とっておく / ❓そのほか
- 記録は後からでもよい。未記録があると「ふりかえり」の先頭と「こうかん」の履歴から入力できる
- **🐖とっておく** を用意したのがポイントで、「もらった＝使った」ではないことを分けて考えさせる

金額の集計は、支出は**その時に渡した実際の円**を使い、収入はポイント×現在のレートで円に直す
(レートを変えると過去の「ためた」も新しいレートで表示される)。

## タスクの設計

| 項目 | 内容 |
|---|---|
| 種類 | **おてつだい** / **べんきょう** の2カテゴリ |
| くり返し | **まいにち**(1日1回)・**まいしゅう**(月曜はじまりの週に1回)・**1回だけ**(達成したら一覧から消える) |
| ポイント | 1タスクごとに親が設定(初期値は3〜10P) |
| 対象 | 全員 / 特定の子だけ(兄弟で難易度を変えられる) |
| 表示 | 絵文字アイコン＋やさしい日本語。低学年でも読めるように漢字は最小限 |

### タスクの増やし方(入口を2つ用意する)

タスクの追加はお金がからむので親モード(PIN)の中に置くが、
**入口は子どもが見ている「きょう」の画面にも出す**。奥に隠れていると増やされないまま形骸化するため。

| 入口 | 動き |
|---|---|
| 「きょう」画面の各グループ末尾の **「＋ ふやす」** カード | 押すと親モードへ。PINを入れるとそのまま作成画面がひらき、押したグループ(おてつだい/べんきょう)が最初から選ばれている |
| 「おうちのひと」→ タスクの設定 → **＋ 新しいタスクをつくる** | 同じ作成画面。既存タスクの編集・削除もここから |

ポイントは 3/5/10/20/50P のボタンで即決でき、それ以外は数字を直接入れる。
入力中は「◯ポイント（◯円）」と円換算が出るので、いくらの仕事なのかを決めながら作れる。

同じタスクを同じ日に二重申告できないよう、申告済み(承認まち含む)のタスクは
「まってね」表示にして押せなくする。

### 初期タスク(そのまま使える)

**おてつだい**: 食器をはこぶ(3P) / 食器をあらう(10P) / おふろそうじ(10P) /
せんたくものをたたむ(10P) / ゴミを出す(5P) / くつをそろえる(3P) /
つくえの上をかたづける(5P) / 買い物のおてつだい(10P)

**べんきょう**: 宿題をやった(10P) / 音読(5P) / 漢字ドリル1ページ(5P) /
計算ドリル1ページ(5P) / 自主学習(10P) / 読書15分(5P) / 明日のじゅんび(3P)

## 親モードのロック

- 4桁のPINで親モードに入る。未設定のうちは入るときに「PINを決める」案内を出す
- PINは端末内(LocalStorage)に保存する簡易ロック。
  **これは“子どもがうっかり触らないための鍵”であって、暗号的な安全性はない**
  (端末の中を見られたら読める)。お金そのものを扱うわけではないので、この強さで十分と判断
- 親モードは一定時間(5分)操作がないと自動でロックに戻る

## 言葉づかいの方針

子どもが読む画面(きょう・きろく・こうかん)は、**小学校低学年が声に出して読める言葉**にする。

| つかわない言葉 | このアプリでの言い方 |
|---|---|
| 承認まち | おうちのひとまち / まってるところ |
| 承認する(親側) | OKする / ぜんぶOKする |
| 申請する | おねがいする |
| 却下 | もどす |
| 残高・換金 | つかえるポイント / おこづかいに かえる |
| 記録がありません | きょうは まだ ないよ |

漢字は「食器・宿題・音読」のような日常語だけにとどめ、
それ以外はひらがな＋分かち書き(「あと 2,980円」のように語のあいだを空ける)にする。

## やらないこと(意図的に外したもの)

| 外したもの | 理由 |
|---|---|
| ポイントの自動減点(ペナルティの自動化) | 「やらなかったら減る」は続かない子が心を折られやすい。減点は親が理由つきで手動で行う形だけ残す |
| 勉強タイマー・テスト点数ボーナス・れんぞく日数 | ヒアリングで「チェック式のみ」と決定。データ構造上あとから足せる形にはしておく |
| サーバー・アカウント | 子どもの生活記録を外部に出さないため。端末内で完結させる |
| 端末間の自動同期 | サーバーを持たないため。代わりに設定からJSONのバックアップ書き出し/読み込みができる |
| アプリ内での実際の送金 | 現金の受け渡しは親が行い、アプリは記録だけを持つ |
