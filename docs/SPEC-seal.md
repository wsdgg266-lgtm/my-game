# 🃏 シールコレクションアプリ 仕様書

> **実装状況**: `seal/` に実装済み(アプリ名: **シールアルバム**)。

**鬼滅の刃 ディフォルメシールウエハース 其ノ十五** のシールを、
スマホで写真に撮って集めていくコレクションアプリ。

既存アプリ(かいわすれナシ!・スポカレ!・ふくらぶ・ピコラン!・ハナビカメラ・
キタイベ!・ジャマケシ・おてつだいバンク・バスナビ!)と同じ構成で作る:

- ビルド不要・単一HTML(`seal/index.html`)・依存ライブラリなし
- PWA対応(ホーム画面に追加してフルスクリーンで起動)
- 写真は端末の外に一切送信しない(処理はすべてブラウザ内で完結)

## 決定事項

| 項目 | 決定 |
|---|---|
| 対象商品 | 鬼滅の刃 ディフォルメシールウエハース 其ノ十五(2026年8月3日発売・全39種、シークレット3種を含む) |
| シール一覧 | **No.1〜No.39 の空き枠を用意し、名前とレアリティはユーザーが入力する**。公式のキャラ名リストは埋め込まない |
| 名前の入力補助 | 作品の登場人物名をサジェストとして出す。あくまで入力補助で、公式ラインナップ表ではない旨を明記する |
| 中核機能 | 写真を撮る → **四隅の自動検出 → 台形補正 → 背景の透明化** → 枠に登録 |
| 処理場所 | **完全に端末内**。API キーも通信も使わない |
| 保存先 | **IndexedDB**。写真は Blob、状態は JSON。localStorage は写真に容量が足りないので使わない |
| ダブり | 枠ごとに**所持枚数**を持ち、2枚以上をダブりとして扱う |
| 交換 | ダブり・未所持の一覧と、そのままコピーできる**交換募集の文面**を自動生成する |
| レアリティ | 未設定/ノーマル/レア/5thレア/無限レア/シークレット。色分け表示と種類別コンプ率 |
| 入手メモ | 日付は自動記録。場所・値段のような細かい家計簿機能は作らない(自由メモ1行のみ) |
| 弾の切り替え | 作らない。枠数とアルバム名を変更できるようにして代替する |

## 画面構成

下タブで4画面を切り替える。ヘッダーの下に常時コンプ率(リング+のこり種類数)を表示。

| タブ | 内容 |
|---|---|

| 🔁 こうかん | ダブり一覧・未所持一覧・交換募集の文面(コピー/共有) |

| ⚙️ データ | アルバム名、枠数の増減、バックアップの書き出し/読み込み、やりなおし |

そのほかの画面(オーバーレイ):

- **カメラ**: 全画面プレビュー・シャッター・インアウト切替・ライト・写真から選ぶ。
  カメラが使えないときはエラー表示と「🖼 写真から選ぶ」を出し、操作不能にならないようにする
- **切り抜きの調整**: 四隅のドラッグ、虫めがね、自動検出やり直し、写真全体、90度回転、
  「まわりを透明に」の切り替え、右上に**できあがりの見本**
- **保存先えらび**: 空き枠/すべての枠から登録先を選ぶ
- **詳細シート**: 写真・名前・レアリティ・枚数・メモの編集、撮り直し、写真削除

## 画像処理

すべて canvas 上で自前実装する。

### 1. 四隅の自動検出 `detectQuad()`

1. 長辺200pxに縮小
2. 外周の帯から背景色を推定(チャンネルごとの中央値)
3. 背景色との距離を**大津の二値化**でしきい値化してマスクを作る
4. ノイズ除去(収縮→膨張)のあと**連結成分**を求め、いちばん大きいかたまりを選ぶ
   (画面のほぼ全面を覆うものは背景とみなして除外、ふちに接するものは減点)
5. かたまりの**凸包**を取り、面積が最大になる4点を選ぶ(四隅の目安から山登りで改善)
6. 左上→右上→右下→左下に並べ替え、元のサイズに戻す

見つからなければ中央84%の長方形にフォールバックする。

### 2. 台形補正 `warpQuad()`

単位正方形 → 四角形 の射影変換を閉じた式で求め、
出力の各画素から逆に引いてバイリニア補間でサンプリングする。
出力サイズは四辺の長さから決め、長辺760pxに収める。

### 3. 背景の透明化 `removeBackground()`

台紙の白を消して、シールの形だけを残すための処理。

1. ごく外側(2%)の画素を **k-means(k=2)** で分け、背景色を最大2色求める
   (「濃い机の上に白い台紙」のように2色写っていても両方拾えるようにする)
2. ふちの画素をすべて種にして塗りつぶしを広げる。広げる条件は
   **背景色に近い(tol)** か、**そこそこ近く(tolHi)かつ隣と地続き(LOCAL)**。
   2つめは境目のぼけや影をたどるための逃げ道で、上限を付けないとにじみ伝いに本体まで食い込む
3. 残った部分を連結成分に分け、**ごく小さなかけら**と**ふちに残ったにじみの輪**を捨てる
4. 消しすぎ防止のチェック(残りが5%未満 / 残りがバラバラに割れている)に引っかかったら、
   背景色を「多い色だけ」「少ない色だけ」と変えて再挑戦する。それでもだめなら**四角いまま**にする
5. アルファを3x3でぼかしてふちをなめらかにし、残った部分の大きさに切り詰める

透明化できたかどうかを呼び出し側に返し、できたときだけ WebP/PNG(アルファ付き)、
できなかったときは JPEG で保存する。見送ったときはその旨をトーストで伝える。

## データ構造

```js
// IndexedDB: sealalbum
//   kv     : 'state' → 下のオブジェクト
//   photos : { id, full: Blob, thumb: Blob }
{
  version: 1,
  title: '鬼滅の刃 ディフォルメシールウエハース 其ノ十五',
  slots: [
    {
      no: 1,            // 通し番号(1始まり・表示にも使う)
      name: '',         // シールの名前(ユーザー入力)
      rarity: '',       // '' | 'normal' | 'rare' | 'fifth' | 'mugen' | 'secret'
      count: 0,         // 所持枚数(0=未所持, 2以上=ダブり)
      memo: '',
      photoId: null,    // photos ストアのキー
      gotAt: null       // 最初に所持した日時(ミリ秒)
    },
    // …No.39 まで
  ]
}
```

## バックアップ

- **写真ごと**: 写真を dataURL にして1つの JSON にまとめる
- **文字データだけ**: 写真を含めない軽いファイル(読み込むと写真は消える)
- 読み込みは現在のデータを置きかえる(内容を確認するダイアログを挟む)

## 作らないもの

- サーバー同期・アカウント・SNS投稿機能
- シール画像の自動認識(どのキャラかをAIが当てる機能)
- 公式ラインナップの埋め込み(誤った情報を配らないため)
