# 🪄 写真の「じゃまなもの」消しアプリ 仕様書

> **実装状況**: `retouch/` に実装済み(アプリ名: **ジャマケシ**)。

撮った写真に写り込んでしまった**じゃまなもの**(通行人、電線、看板、ゴミ箱、
自分の指、写り込んだ影など)を、指でなぞるだけで消せるアプリ。

ただ消すだけなら塗りつぶせばよいが、それでは「消した跡」が残ってしまう。
このアプリは消した場所を**まわりの絵柄から作り直して**埋めるので、
最初からそこに何も無かったように見える。

既存アプリ(かいわすれナシ!・スポカレ!・ふくらぶ・ピコラン!・ハナビカメラ・キタイベ!)と
同じ構成で作る:

- ビルド不要・単一HTML(`retouch/index.html`)・依存ライブラリなし
- PWA対応(ホーム画面に追加してフルスクリーンで起動)
- 写真は端末の外に一切送信しない(処理はすべてブラウザ内で完結)

## 決定事項

| 項目 | 決定 |
|---|---|
| 中核機能 | **なぞった場所を、まわりの絵柄から作り直して消す**(内容認識塗りつぶし) |
| 処理場所 | **完全に端末内**。AI サーバーも API キーも使わない(通信ゼロ・無料・オフライン可) |
| 対応デバイス | **iPhone / Android / PC**。指でもマウスでも同じ操作 |
| 範囲の指定 | **なぞる(ブラシ)** と **かこむ(なげなわ)** の2つ。消しすぎたらマスク消しゴムで削る |
| 保存 | **端末に保存(ダウンロード)**のみ。SNS共有ボタンやアプリ内ギャラリーは作らない |
| 元写真 | 上書きしない。加工結果を別ファイルとして保存する |

## 画面構成

```
┌─────────────────────────────┐
│ 🪄 ジャマケシ    [↩][↪]  [？] [保存] │ ← ヘッダー
├─────────────────────────────┤
│                                     │
│         写真(ピンチで拡大・移動)      │
│         赤い部分 = 消す範囲          │
│                                     │
├─────────────────────────────┤
│ [🖌なぞる][⭕かこむ][🧽けずる][✋うごかす] │ ← 道具
│ ふとさ ●────────                    │
│ しあがり [はやい|きれい|じっくり]      │
│        ( ✨ ここを消す )             │
└─────────────────────────────┘
```

## 1. 消す範囲の指定(マスク)

写真の上に赤い半透明で重ねて表示する。範囲の作り方は3つ。

| 道具 | 動き |
|---|---|
| 🖌 なぞる | 指でなぞった線が範囲になる。太さはスライダーで変更(画面上の見た目の太さで指定するので、拡大しても指の感覚が変わらない) |
| ⭕ かこむ | 囲んだ内側がまるごと範囲になる。人や看板など、かたまりを消すとき用 |
| 🧽 けずる | 範囲をはみ出して塗ったところを削る |
| ✋ うごかす | 1本指で写真を動かす(2本指のピンチはどの道具でも使える) |

- 範囲の操作は**1手ずつ取り消せる**(ヘッダーの ↩ / ↪)。取り消し履歴は
  「線の並び」として持ち、取り消し時に引き直すので、大きな写真でもメモリを食わない
- 2本目の指が触れた時点で書きかけの線は取り消し、ピンチ操作に切り替える
  (拡大しようとして線を引いてしまう事故を防ぐ)

## 2. 消す処理(内容認識塗りつぶし)

「まわりに似ている絵柄を写真の中から探してきて、消す場所に少しずつ貼り合わせる」
という方式(PatchMatch 法)。空・芝生・砂・壁・水面のような**くり返しのある背景**に強く、
消したい物のまわりに似た景色があるほどきれいに埋まる。

### 手順

1. **切り出し**: 消す範囲を囲む四角形に、まわりの余白(範囲の 0.8 倍、最低 40px)を
   足した部分だけを切り出す。写真全体ではなく周辺だけを扱うので、
   大きな写真から小さな物を消すときは**縮小なしの原寸のまま**処理でき、速くて劣化しない
2. **段階的に解像度を上げる**: 切り出した画像を半分ずつ縮小したピラミッドを作り、
   いちばん粗い段(短辺 48px 程度)から順に埋めていく。
   粗い段でおおまかな構図(地平線や壁の境目)を決め、細かい段で質感を作る
3. 各段でこの2つを数回くり返す:
   - **さがす**: 消す場所の 7×7 のパッチごとに、「消す範囲に一切かかっていない場所」から
     いちばん似ているパッチを探す。総当たりだと遅すぎるので PatchMatch
     (ランダムな初期値 → 隣の当たりを伝播 → 半径を半分ずつ狭めるランダム探索)で探す
   - **ぬる**: 見つかったパッチを重ね合わせ、似ている度合いで重み付けした平均で塗る
4. **戻す**: 埋め終わった絵を元の大きさに拡大し、**ふちをぼかしたマスク**で
   元写真に合成する。範囲の外側は 1px も変化しない

境界がなじむよう、パッチの似ている度合いを測るときは
**まだ消えていない(既知の)画素を2倍重く**扱う。これで、消した場所とまわりの
つなぎ目がずれにくくなる。

### しあがりの3段階

処理量は解像度の2乗で効くので、切り出した部分の長辺の上限で速さと質を選べるようにする。

| モード | 長辺の上限 | 目安 |
|---|---|---|
| はやい | 480px | 1〜2秒。とりあえず消せるか試すとき |
| きれい(初期値) | 820px | 3〜6秒。ふだん使い |
| じっくり | 1200px | 10秒前後。細かい模様を残したいとき |

### 実行中の扱い

- 計算は **Web Worker** に逃がし、画面が固まらないようにする。
  進み具合をバー(%)で表示し、**キャンセル**もできる(Worker を止めて作り直す)
- Worker が使えない環境ではメインスレッドで同じコードを実行する(その場合キャンセル不可)
- 埋め方には乱数を使うので、同じ範囲でも結果が変わる。気に入らないときは
  **「別の結果にする」**で、直前の結果を取り消して乱数の種を変えてやり直せる

## 3. 写真の読み込みと保存

- 読み込み: ファイル選択(カメラ撮影も可)、PC ではドラッグ&ドロップと貼り付けに対応
- `createImageBitmap(file, { imageOrientation: 'from-image' })` で
  **EXIF の回転を反映**して読む(スマホの縦写真が横向きになるのを防ぐ)
- 長辺 2400px を超える写真は 2400px に縮めてから扱う(スマホのメモリ対策)
- 保存: JPEG(品質 0.95)で `jamakeshi-YYYYMMDD-HHMMSS.jpg` としてダウンロード

## 4. 取り消し(元に戻す)

- 消す処理の取り消しは、**書き換えた四角形の中の画素だけ**を控えておいて戻す。
  写真全体を控えないので、何手でも安く戻せる
- 履歴は30手まで

## やらないこと

- サーバー送信・クラウドAI(通信ゼロという性質を壊すため)
- 明るさ・色調整・フィルタ(このアプリは「消す」ことに絞る)
- 動画

## うまくいかないとき(アプリ内ヘルプにも書く)

- **消したい物のふちが残る** → 少し大きめに、影まで含めてなぞる
- **模様がぐにゃぐにゃになる** → 範囲を狭く区切って、何回かに分けて消す
- **人の顔や文字など、まわりに手本が無いものは苦手** → まわりにある景色から
  作り直す仕組みのため、写真のどこにも似た絵柄が無いものは復元できない
