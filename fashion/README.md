# 👗 ふくらぶ - ファッションアプリ

「コーデ診断」「近くのお店」「お得情報」がひとつでわかる、
服がもっと好きになるファッションアプリです。
ビルド不要・サーバー不要で、`fashion/index.html` をブラウザで開くだけで使えます。

仕様は [docs/SPEC-fashion.md](../docs/SPEC-fashion.md) を見てください。

## 使い方

`index.html` をブラウザ(スマホ推奨)で開くだけです。
データはブラウザの LocalStorage に保存されるので、閉じても消えません。

公開 URL(GitHub Pages 有効化後):
`https://wsdgg266-lgtm.github.io/my-game/fashion/`

PWA 対応なので、スマホで開いて「ホーム画面に追加」すると
アプリのようにアイコンから起動できます。

## 機能

- **📷 コーデ診断**: 今日の服装をカメラで撮る(またはアルバムから選ぶ)と、
  写真の配色を読み取って点数とアドバイスを表示。
  季節(自動判定・変更可)とシチュエーション(仕事・デート・お出かけなど)に
  合わせて、色数・明るさ・暖色寒色のバランスなどからコメントします。
  アドバイスに合わせた**おすすめアイテム**も提示し、好きなショップ
  (楽天市場・ZOZOTOWN・Amazon・ユニクロなど+登録ブランド。設定で選択)の
  検索結果にワンタップで飛べます。
  診断結果は履歴に残り、あとから見返せます。
  **写真は端末の中だけで処理され、どこにも送信されません。**
- **🛍️ お店**: よく行くお店の登録(地図・公式・セール情報にワンタップ)、
  Googleマップでの周辺検索(古着屋・ファッションビル・アウトレットなど)、
  登録ブランドの店舗検索
- **🏷️ お得**: 年間セールカレンダー(夏冬バーゲン・楽天スーパーセール・
  ブラックフライデーなどをプリセット内蔵、編集・追加可)、
  開催中・まもなくのセールを起動時にお知らせ、ブランドのセール・クーポンリンク
- **⚙️ 設定**: ブランド管理、住所(周辺検索用)、診断履歴の削除

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル構成(依存ライブラリなし)
- コーデ診断は Canvas による端末内の色解析(外部AI・外部送信なし)
- LocalStorage によるデータ永続化・PWA(オフライン対応)
- モバイルファーストのレスポンシブデザイン
