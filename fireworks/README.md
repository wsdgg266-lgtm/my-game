# 🎆 ハナビカメラ - 花火がきれいに撮れるカメラ

スマホで花火をきれいに撮るためのカメラアプリです。
ビルド不要・サーバー不要ですが、**カメラを使うには https の公開URLで開く必要があります**。

## なぜ普通のカメラだとうまく撮れないのか

花火は一瞬で消えるので、普通に撮ると**点みたいにしか写らない**か、
明るさが合わずに**白く飛ぶ**かのどちらかになりがちです。
きれいな花火写真は本来、カメラを三脚に固定して数秒間シャッターを開けっぱなしにする
「長時間露光」で撮るもので、スマホの標準カメラでは難しい撮り方です。

このアプリは、シャッターを押している間カメラの映像を高速に取り込み続けて、
各コマの**明るい部分だけを重ねます**(比較明合成)。
暗い夜空はそのまま暗いままで、花火の光跡だけが伸びていくので、
長時間露光で撮ったような1枚ができあがります。

## 使い方

1. 公開URLをスマホで開いて、カメラを許可する
2. 撮りたい花火の種類に合わせて**プリセット**を選ぶ
3. 打ち上がる音が聞こえたら**シャッターを押しっぱなし**にする
   (短くタップすると、上限秒数まで撮りっぱなしになります。もう一度タップで停止)
4. 指を離すと**仕上げ画面**へ。夜空のかぶりを取った状態で表示されます
5. スライダーで好みに調整して「保存する」

### プリセット

| プリセット | 合成する秒数 | 向いている花火 |
|---|---|---|
| 打ち上げ | 4秒 | 単発。1発が開いて散るまでをまるごと1枚に |
| スターマイン | 8秒 | 連発。重ねすぎて真っ白にならないよう古い光跡から消していく |
| 仕掛け花火 | 6秒 | ナイヤガラなど光の量が多いもの |

### 🖼 写真から合成

すでにカメラロールにある花火写真も読み込めます。
**複数枚選ぶと比較明合成で1枚にまとまり**、1枚だけなら仕上げ調整だけかかります。

## 仕上げの調整

| 項目 | 効果 |
|---|---|
| かぶり除去 | 街明かりで茶色く浮いた夜空を黒に戻す。花火写真で一番効く調整 |
| 明るさ | 花火の淡い部分を持ち上げる/落とす |
| コントラスト | 夜空と花火のメリハリ |
| 鮮やかさ | 花火の色を出す。上げすぎると不自然になります |

## ⚙ 詳細モード

歯車ボタンで開きます。かんたんに撮りたいときは開かなくて大丈夫です。

- **合成する秒数の上限**(1〜15秒)
- **明るさ(露出)**: 白く飛ぶときはマイナスに
- **光跡の残り**: 100%だと光跡が全部残る。下げるほど古い光跡から消えていく
- **ピント固定 / ホワイトバランス固定**: 暗い夜空でピントや色が迷うのを防ぐ
- **三分割グリッド**: 構図合わせ用
- **手ブレ警告**: 撮影中に端末が揺れたら警告を出す
- **カメラ制御の対応状況**: 露出・ピント・WB のどれが端末で効いているかを表示

端末やブラウザによって使える制御が違うため、使えるものだけを自動で適用します。
iPhone はブラウザからシャッター速度やISOを指定できないので、
長時間露光は連写＋合成で再現しています(それでも十分きれいに撮れます)。

## 撮り方のコツ

- **端末を固定する**(手すり・三脚・カバンの上)。合成中に動くと光跡が二重になります
- **打ち上がる音が聞こえたらシャッター**。開いてから押すと間に合いません
- **横位置で空を広めに**。花火は思ったよりずっと大きく開きます

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル構成(依存ライブラリなし)
- カメラ: `getUserMedia` + `MediaStreamTrack.applyConstraints`(対応している制御のみ適用)
- 合成: Canvas 2D の `globalCompositeOperation = 'lighten'`(比較明合成)。
  光跡の減衰は `multiply` でグレーを重ねて実現
- 仕上げ: ヒストグラムから夜空の明るさをチャンネルごとに求め、256段のLUTで一括変換。
  画面表示は縮小画像、保存時だけ元の解像度で処理
- 写真はすべて端末内で処理され、**外部に送信されません**
- PWA対応(ホーム画面に追加でフルスクリーン起動)
- LocalStorage: 撮影設定のみ保存(写真は保存しません)

## iPhone / Android で使う(ホーム画面に追加)

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」または「アプリをインストール」**
