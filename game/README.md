# 🎮 ピコラン! - ぴょんぴょんだいぼうけん

ドット絵風の横スクロールジャンプアクションゲームです。
主人公「ピコ」を操作して、敵をふんで、コインをあつめて、ゴールをめざします。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで遊べます。

## あそびかた

- **◀ ▶ ボタン**(画面左下): 左右にうごく
- **Ⓐ ボタン**(画面右下): ジャンプ。**ながおしで大ジャンプ**
- スマホは**よこもち推奨**。PCなら矢印キー+スペース(またはZ)でも遊べます

### ルール

- 敵は**上からふむ**と倒せる(よこから触れるとダメージ)
- **とげとげ**(トゲのある敵)はふめないので避ける
- コインは1枚スコア+10、**100枚あつめると残機+1**
- **?ブロック**を下から叩くとコインが出る。**ハートの実**を取るとパワー状態になり、ダメージを1回耐えられる(パワー中はレンガをこわせる)
- 残機3でスタート。ミスすると**ちゅうかん地点(旗)**から再開、残機0でゲームオーバー
- さいごのステージ「おしろ」のボスは**3回ふみつける**と勝ち!

## ステージ

| # | テーマ | とくちょう |
|---|---|---|
| 1 | 🌿 くさはら | やさしい入門ステージ |
| 2 | 🕳️ どうくつ | おちるゆか・とげとげ・ふわふわ |
| 3 | ☁️ そら | 浮島ジャンプ・動く足場 |
| 4 | 🏰 おしろ | ようがん(即ミス!)+ボス戦 |

クリアすると次のステージがアンロックされます。ハイスコアはステージごとに保存されます。

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル構成(依存ライブラリなし)
- グラフィック: `<canvas>` 320×180相当の低解像度に描いて拡大するドット絵表示。画像ファイルは不使用(すべてコードで描画したオリジナルデザイン)
- サウンド: Web Audio でBGM・効果音を合成(音声ファイル不使用)。タイトル画面・ポーズ画面でON/OFF切替
- 物理: 固定タイムステップ(60fps相当)+タイルベースの当たり判定。コヨーテタイム・ジャンプ先行入力など操作が優しく感じる仕組み入り
- ステージデータ: テキストの地図(文字=ブロック種別)。`index.html` 内の `LEVELS` を編集すればステージを追加・調整できる
- PWA対応(ホーム画面に追加でフルスクリーン起動・オフライン動作)
- LocalStorage: アンロック状況・ステージ別ハイスコア・サウンド設定を保存

## iPhone / Android で使う(ホーム画面に追加)

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」または「アプリをインストール」**
