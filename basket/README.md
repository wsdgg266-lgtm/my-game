# 🏀 バスナビ! - B.LEAGUE / NBA / 日本代表の試合と順位

B.LEAGUE・NBA・バスケットボール日本代表について
「今日どの試合があって、どこで見れて、順位はどうなっているか」が1画面でわかるアプリです。
日本のバスケットボール関連ニュースもまとめて読めます。
ビルド不要・サーバー不要で、`basket/index.html` をブラウザで開くだけで使えます(PWA対応)。

公開URL: `https://wsdgg266-lgtm.github.io/my-game/basket/`
(スマホで開いて「ホーム画面に追加」すればアプリとして使えます)

## 画面

下部のタブは **ホーム / 試合 / 順位 / 選手 / ニュース / 設定** の6つです。

- **🏠 ホーム**: フォロー中チーム(未登録なら日本代表)の**次の試合までの日数**を大きく表示。
  そのあとに今日の試合、日本代表の次戦、最新ニュースが並びます
- **🏀 試合**: 「これから」「結果」を上部で切り替え。日付ごとに一覧
- **📊 順位**: NBAは東西カンファレンス別に、**プレーオフ進出圏(上位6)とプレーイン圏(7〜10位)を
  線と色で区切って**表示。勝率・ゲーム差・直近10試合・連勝連敗つき。B.LEAGUEは地区別の順位表
- **🧑‍🎽 選手**: NBAでプレーする**日本出身選手**の今季成績(得点・リバウンド・アシスト・出場時間)と
  自動の★評価、NBAの部門別リーダー、日本代表の招集メンバー
- **📰 ニュース**: 日本のバスケットボール関連ニュースを各社のRSSから集めて新しい順に表示。
  見出しをタップすると配信元の記事が開きます
- **⚙️ 設定**: 画面の明るさ、リーグの表示切替、放送の初期表示の編集、フォロー中チーム、診断

### 画面の明るさ

初期は**明るい画面**です。ヘッダー右上の 🌙 / ☀️ ボタン(または設定タブ)で暗い画面に切り替えられます。
選んだ状態は端末に保存され、次に開いたときもそのままです。

### 試合カードの見かた

スコアボードのように**ホームを上・アウェイを下**に並べ、左端の色はチームカラー(NBAは実際のチームカラー)です。
勝ったチームは白く太字になり、試合中は経過(第3Q 残り5:21 など)が赤く点滅します。
NBAはクォーター別スコアも出ます。

### 📺 放送・配信を探す

どの試合カードにも「放送を探す」ボタンがあります。押すと、その試合を**どこで見られるか探せる場所**が並びます。

- **日本代表**: 大会ごとに放送局が変わるため、
  **テレビ番組表(Yahoo!テレビ)・TVer・NHK番組表・JBA公式・FIBA公式**をまとめて開けます
- **B.LEAGUE**: バスケットLIVE、公式の日程ページ、テレビ番組表
- **NBA**: NBA Rakuten、NBA League Pass、テレビ番組表

調べた結果は「この試合の放送をメモする」で試合カードに残せます(例: `NHK BS1 で 20:00〜`)。
リーグごとの初期表示は設定タブで変更できます。

### そのほか

- **⭐ チームのフォロー**: 試合カードや順位表のチーム名をタップして登録。
  「このチームだけ表示」でアプリ全体を絞り込み
- **🔴 ライブスコア**: 試合中は1分ごとに自動更新
- **🩺 診断**: 設定タブで、どのデータがどこから何件取れたかを確認できる

## データについて

| 対象 | 取得元 | 方式 |
|---|---|---|
| NBA の日程・結果・ライブスコア | ESPN | ブラウザが直接取得(APIキー不要) |
| NBA の順位表・部門別リーダー | ESPN | ブラウザが直接取得 |
| B.LEAGUE の日程・結果・順位表 | TheSportsDB | GitHub Actions が毎日取得して `basket/data/bleague.json` に保存 |
| バスケ日本代表の試合 | TheSportsDB | 同上(`basket/data/japan.json`) |
| NBAの日本人選手 | ESPN のチームロスター | 同上(`basket/data/nba-jp.json`) |
| ニュース | 各社のRSS(`basket/data/news-sources.json` に定義) | 同上(`basket/data/news.json`) |

- **なぜ一部だけサーバー側で取るのか**: ブラウザから直接よそのサイトを読むと CORS で弾かれるため、
  ブラウザから読めない分は GitHub Actions(サーバー側)で取得し、結果をこのリポジトリに置いています。
  アプリは同一オリジンの JSON を読むだけなので、APIキーもサーバーも要りません
- 取得したデータは LocalStorage にキャッシュされ、オフラインでも最後に取得した内容を表示します
- TheSportsDB は有志更新のため、日本のリーグは反映が遅れたり抜けたりすることがあります。
  各試合カードの公式サイトリンクで正確な情報を確認できます
- 放送・配信チャンネルの自動データは存在しないため、リーグごとのプリセット(編集可)+
  試合ごとの手動メモ + 検索リンクで補う設計です
- 選手の★評価は「得点+リバウンド+アシスト」から機械的に付けたもので、公式の評価ではありません
- ニュースは見出しとリンクだけを保存し、本文は取り込みません(記事は配信元のサイトで開きます)。
  スポーツ全般のフィードからは、`news-sources.json` の `keywords` に当てはまる記事だけを拾います

### ニュースの取り込み元を足したいとき

`basket/data/news-sources.json` の `feeds` にRSSのURLを足すだけです。
バスケ専門のサイトは `filter: false`、スポーツ全般のサイトは `filter: true` にします。
動かなかったソースは診断画面に理由が出るので、それを見て `enabled: false` にできます。

### 自動更新の初回設定

`.github/workflows/basket-import.yml` が毎日3:30(日本時間)に動きます。
**初回は Actions タブ → Import basketball data → Run workflow で手動実行**し、
`basket/data/import-report.json`(アプリの「設定 → 診断」でも見られます)で
どのソースが使えたかを確認してください。

1件も取れなくてもアプリは動きます(NBAの日程・結果・順位表はブラウザが直接 ESPN から取るため)。

### 手で書き足したいとき

日本代表の大会日程が自動で取れない場合は、`basket/data/japan.json` の
`manualGames` と `roster` に書き足せます。ここは自動更新でも消えません。

```json
{
  "manualGames": [
    { "id": "wc-q1", "ts": 1793491800000, "timeJst": "20:10",
      "home": "Japan", "away": "China", "venue": "有明アリーナ", "label": "W杯アジア予選" }
  ],
  "roster": [
    { "no": 8, "name": "八村塁", "team": "Los Angeles Lakers", "pos": "PF" }
  ]
}
```

## 開発

```bash
node scripts/test-basket-import.mjs   # 取り込みロジックの単体テスト(ネットワーク不要)
node scripts/import-basket.mjs        # データ取り込みを手元で実行
node scripts/make-basket-icons.mjs    # PWAアイコンを作り直す
```

## 技術構成

- HTML / CSS / JavaScript のみの単一ファイル構成(依存ライブラリなし)
- LocalStorage によるデータ永続化、Service Worker によるオフライン対応(PWA)
- モバイルファーストのレスポンシブデザイン
