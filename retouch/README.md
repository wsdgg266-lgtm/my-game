# 🪄 ジャマケシ - 写真のじゃまなものを消す

撮った写真に写り込んでしまった**じゃまなもの**を、指でなぞるだけで消せるアプリです。

- 前を横切った通行人
- 空にかかった電線・電柱
- 景色をさえぎる看板やゴミ箱
- レンズにかかった自分の指、写り込んだ影

ただ塗りつぶすのではなく、**まわりの景色から作り直して**埋めるので、
最初からそこに何も無かったように見えます。

ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで使えます。

## 使い方

1. **写真をえらぶ**(スマホならその場で撮ってもOK)
2. 消したいものを**なぞる**。かたまりは「かこむ」でぐるっと囲むほうが早い
3. **「✨ ここを消す」**を押す
4. 気に入らなければ **↩** で戻すか、**「🎲 別の結果にする」**で別の埋め方を試す
5. **保存**で端末にダウンロード(元の写真はそのまま残ります)

### 道具

| 道具 | 使いどころ |
|---|---|
| 🖌 なぞる | 電線・細い棒など、線状のものをなぞって消す。太さはスライダーで変更 |
| ⭕ かこむ | 人や看板など、かたまりをまるごと囲んで消す |
| 🧽 けずる | 塗りすぎた範囲を削る |
| ✋ うごかす | 写真を動かす(2本指のピンチはどの道具のときでも使えます) |

細かいところは**2本指でピンチして拡大**してから塗ると正確です。

### しあがりの3段階

| モード | 目安の速さ | 向いている場面 |
|---|---|---|
| はやい | 1〜2秒 | 消せるかどうか、まず試したいとき |
| きれい | 3〜6秒 | ふだん使い(初期値) |
| じっくり | 10秒前後 | 細かい模様をできるだけ残したいとき |

## しくみ

「まわりに似ている絵柄を写真の中から探してきて、消す場所に貼り合わせる」という方式です
(PatchMatch 法)。

1. 消す範囲のまわりごと切り出す(手本になる景色を一緒に見るため)
2. 粗い解像度から順に、消す場所の 7×7 のパッチごとに
   **「消す範囲に一切かかっていない場所」から、いちばん似ているパッチ**を探して重ねる
3. 粗い段でおおまかな構図(地平線や壁の境目)を決め、細かい段で質感を作る
4. 最後にふちをぼかして元の写真に戻す。**範囲の外は1画素も変化しません**

計算は Web Worker で行うので、処理中も画面は固まりません。

### 得意なもの・苦手なもの

- **得意**: 空・壁・芝生・砂浜・道路・水面など、まわりに似た景色が続いているところ
- **苦手**: 写真のどこにも手本が無いもの(消した先に隠れている人の顔や文字など)。
  まわりの景色から作り直す仕組みなので、無いものは復元できません

うまくいかないときは、**範囲を狭く区切って何回かに分けて**消すときれいになります。

## iPhone / Android で使う(ホーム画面に追加)

PWA 対応です。公開 URL をスマホで開いてホーム画面に追加すると、
普通のアプリのようにアイコンから全画面で起動でき、**オフラインでも動きます**。

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」**

## プライバシー

写真は**端末の外に一切出ません**。読み込みも加工も保存も、すべてブラウザの中だけで
完結します。サーバーにも AI サービスにも送信しないので、通信が無くても使えます。

## 技術構成

- 単一 HTML(`index.html`)・ビルド不要・外部ライブラリなし
- 埋め処理は Web Worker(HTML 内にインラインで持ち、Blob URL から起動)
- Worker が使えない環境では同じコードをメインスレッドで実行(その場合のみ中断不可)
- 読み込む写真は長辺 2400px までに縮小(スマホのメモリ対策)
- 取り消しは、範囲の操作は「線の並び」、消す処理は「書き換えた四角形の中の画素」だけを
  控える方式。写真全体を控えないので何手でも軽い

詳しい仕様は [`../docs/SPEC-retouch.md`](../docs/SPEC-retouch.md) を参照してください。
