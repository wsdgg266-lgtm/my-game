# 🪙 おてつだいバンク

小学生の子ども向けの「おてつだい・べんきょう → ポイント → 本物のお小遣い」アプリ。
ビルド不要・サーバー不要で、`points/index.html` をブラウザで開くだけで使えます。

仕様の背景や決定事項は [../docs/SPEC-points.md](../docs/SPEC-points.md) を見てください。

## つかいかた(3ステップ)

1. **おうちのひと**タブを開いて、好きな4桁の数字を入れる(それがPINになります)
2. 「子どもの管理」で名前とアイコンを決める(兄弟の分もふやせます)
3. 子どもが**きょう**タブでできたことをタップ → おうちの人が**承認** → ポイントがたまる

たまったポイントは**こうかん**タブから「◯円にかえる」と申請でき、
おうちの人が現金を渡して「わたした」を押すと完了です。

## 機能

- **🎯 ちょきんの めあて**: ほしいもの(絵文字・名前・ねだん)を決めると、
  「きょう」タブのいちばん上に進みバーが出て、**あと◯円（◯P）**が一目でわかります。
  たまると「🎉 たまったよ!」に変わり、こうかんの確認画面でも
  「めあてまで あと◯円になるよ」と教えてくれます(子ども自身が設定でき、
  消してもポイントは減りません)
- **🏠 きょう**: おてつだい／べんきょうのタスクをタップして「できた!」と申告。
  同じタスクの二重申告(まいにち=1日1回/まいしゅう=週1回)は自動でブロック。
  申告まちがい は ✕ で自分でとりけせます
- **💰 ポイント＝お金の表示**: 残高はつねに「◯P ＝ ◯円」と併記。
  1ポイントの金額(初期値1円)は設定で変えられます
- **➕ タスクを ふやす**: 「きょう」画面の各グループの最後にある **「＋ ふやす」** をタップすると、
  そのままタスク作成画面がひらきます(おうちの人のPINが必要。PINを入れるとそのまま作成画面に進みます)。
  絵文字・名前・ポイント(3/5/10/20/50Pのボタンか自由入力)・しゅるい・くり返し・だれの分か を決めて保存。
  作ったタスクはすぐ「きょう」に並びます。編集・削除は「おうちのひと」→ タスクの設定から
- **🎁 ポイントを直接あげる/ひく**: 「おうちのひと」→ 子どもの管理 →「🎁 ポイントをあげる」で、
  タスクにないがんばりへのボーナスや、約束を破ったときの調整ができます(理由つきで履歴に残ります)
- **👪 おうちのひと(PINロック)**: 承認まちの一括承認・却下、こうかん申請の処理、
  タスクの追加/編集/削除、子どもの追加・削除、手動でポイントを足す/引く、
  レート・PINの設定、バックアップの書き出し/読みこみ。5分さわらないと自動でロック
- **📊 ふりかえり(おこづかい帳)**: 今月の **ためた − つかった ＝ ふえた分** を式で表示。
  6か月の棒グラフ(ためた／つかった)、**なにに つかった?** の内訳(円と%)、
  **なにで ためた?** の内訳とよくやったことベスト3、
  「1日 やく◯円の ペースだから、めあてまで あと やく◯日」の見通しまで出ます。
  自分の本物のお金の記録で、収入・支出・残高・割合・ペースの計算にふれられます
- **🛍 つかいみちの記録**: 受け取ったお金を 🍭おかし / 🧸おもちゃ / 🎮ゲーム / 📚本 /
  ✏️ぶんぼうぐ / 🎁プレゼント / 🐖とっておく / ❓そのほか から選んで記録。
  あとからでも入力でき、グラフに反映されます
- **📅 きろく**: 今週・今月にためたポイント、これまでにもらった金額、
  今月のスタンプカレンダー、承認まち/承認ずみ/却下がわかる履歴
- **🧾 二重払いの防止**: こうかんを申請した分のポイントは「申請中」として確保され、
  受け取るまで別の用途には使えません。渡した記録も日付つきで残ります
- **兄弟に対応**: 上部のチップで子どもを切り替え。タスクは「ぜんいん」または
  「この子だけ」を選べるので、学年に合わせて内容やポイントを変えられます
- **オフライン対応(PWA)**: ホーム画面に追加すればアプリのように起動でき、
  電波がなくても使えます

## 言葉づかい

子どもが読む画面は、小学校低学年が声に出して読める言葉にしています
(「承認まち」→「おうちのひとまち」、「申請する」→「おねがいする」など)。
漢字は日常語だけにとどめ、ほかはひらがな＋分かち書きにしています。

## データの扱い

- ポイント・履歴・設定は、その端末のブラウザ(LocalStorage)にだけ保存されます。
  子どもの生活記録を外部に送信することは一切ありません
- 端末をまたいだ自動同期はありません。機種変更のときは
  **おうちのひと → バックアップ → 書き出す** でJSONを保存し、新しい端末で読みこんでください
- PINは端末内に保存される簡易ロックです(暗号化はしていません)。
  「子どもがうっかり触らないための鍵」と考えてください

## スマホで使う(ホーム画面に追加)

- **iPhone**: Safari で開き、**共有ボタン → 「ホーム画面に追加」**
- **Android**: Chrome で開き、**メニュー(⋮)→ 「ホーム画面に追加」**
